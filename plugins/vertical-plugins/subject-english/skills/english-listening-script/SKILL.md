# English Listening Script Skill

## 用途

把"听力训练"从"听天由命"提升为"按策略、按考点、可复盘"的能力训练。

## 听力策略

### 三遍听法

| 遍数 | 任务 | 重点 |
|---|---|---|
| 第 1 遍 | 抓主旨 | 听大意，听场景 |
| 第 2 遍 | 抓细节 | 听数字、时间、地点、人物 |
| 第 3 遍 | 校对 | 对照原文，听漏掉的词 |

### 听写策略

- 听一句，写一句
- 不强求一次写对，重点是听清楚
- 写不出空着，最后一遍补

## 触发场景

- 听力错题诊断
- 听力专项训练
- 家长问"怎么练听力"

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| audio_url | ✅ | 音频 URL 或本地路径 |
| transcript | ❌ | 原文（若有） |
| questions | ✅ | 配套题目 |
| student_answers | ❌ | 学生答案（用于诊断） |
| grade | ✅ | 年级 |

## 输出

### `listening_analysis.md`

```markdown
# 听力分析报告

> 素材：教材 Unit 2 Listening Part
> 主题：School Life
> 时长：3:45
> 题数：5
> 学生：xxx

## 一、整体情况

| 维度 | 数据 |
|---|---|
| 总题数 | 5 |
| 正确 | 3 |
| 错误 | 2 |
| 正确率 | 60% |
| 建议时间 | 5 min |
| 实际时间 | 8 min |

## 二、逐题诊断

### q1（细节题，✓ 正确）
- 听音定位：第 1 段对话，"Where does she go after class?"
- 答案：library
- 抓取方式：数字 + 关键词 after class

### q2（细节题，✗ 错）
- 听音定位：第 2 段对话，"When does the club meet?"
- 学生答：Friday
- 正确答案：Tuesday
- 错因：未听清日期，听成了频率副词
- 考点：Tuesday 容易和 Thursday / Friday 混淆
- 补救：精听日期词（day of the week）

### q3（推断题，✗ 错）
- 听音定位：末段
- 学生答：Yes
- 正确答案：No
- 错因：未听懂否定词 "doesn't"
- 考点：don't / doesn't / didn't 缩写
- 补救：精听否定结构

## 三、错因统计

| 错因类型 | 数量 | 占比 |
|---|---|---|
| 同音词混淆 | 1 | 50% |
| 否定词漏听 | 1 | 50% |

## 四、考点预测

听力题常考 7 大考点：

| 考点 | 出现频率 | 训练建议 |
|---|---|---|
| 数字（时间、价格、电话） | ★★★ | 精听数字 1-100 |
| 日期 / 星期 | ★★★ | 精听 Monday-Sunday |
| 否定词 | ★★ | 精听 don't/doesn't/didn't |
| 同音 / 近音词 | ★★ | 对比发音 |
| 人物关系 | ★ | 关注称呼 |
| 地点 / 场景 | ★ | 听背景音 + 关键词 |
| 推断 / 态度 | ★ | 关注语气词 |

## 五、训练计划

### 第 1 周：精听训练
- 每天 1 段 1-2 min 短对话
- 听 3 遍：主旨 → 细节 → 校对
- 写 5 道细节题

### 第 2 周：考点专项
- 数字 + 日期
- 否定词
- 同音词

### 第 3 周：泛听
- 每天 1 篇 5 min 短文
- 1 遍听主旨 + 1 遍听细节

### 第 4 周：综合
- 真题听力模拟

## 六、配套脚本

### 听写脚本（精听）

```
[音频 URL]

第 1 段 (0:00 - 0:30)：
A: Hey, what do you usually do after class?
B: I often go to the library to read books.
A: How often?
B: About three times a week.

第 2 段 (0:30 - 1:15)：
A: ...
B: ...
```

### 跟读脚本（语音模仿）

- 每个停顿 2-3 秒
- 注意连读、失爆、弱读
- 影子跟读（shadowing）3-5 遍
```

## 错因分类

```
error_type:
  - sound_similar        # 同音 / 近音
  - negation_missed       # 漏否定
  - number_missed         # 漏数字
  - long_sentence_lost    # 长句漏信息
  - speed_too_fast        # 语速跟不上
  - vocab_unknown         # 生词卡住
  - attention_lost        # 走神
  - careless              # 粗心
```

## 工作流

```
输入 (audio, questions, student_answers)
  ↓
1. 音频转写（如无 transcript）
   - 用 Whisper / 讯飞
   - 加时间戳
  ↓
2. 题目分类
   - 标记每题：细节/推断/词义
  ↓
3. 学生答题分析
  ↓
4. 错因归类
   - 调误区库
   - 关联到考点
  ↓
5. 考点预测
   - 同主题历史考点
  ↓
6. 训练计划
   - 4 周专项
```

## 质量标准

- 转写准确率 ≥ 95%
- 错因诊断准确率 ≥ 80%
- 训练计划可执行
- 配套脚本可下载

## 护栏

1. **不评判学生**：不写"听力差"
2. **不给"玄学"策略**：不写"多听就懂"
3. **不堆材料**：每天 1 段就够
4. **不脱离教材**：素材基于教材
5. **可执行**：训练时间明确

## 不要做的事

- 不要把听力讲成"靠语感"
- 不要堆"高级听力材料"（基础薄弱学生做不来）
- 不要在嘈杂环境推荐（家长监督）
- 不要一次性给 5 篇听力
- 不要直接给答案（用提问引导）

## 依赖

- Whisper（语音转文字）
- 教材音频库
- 中高考听力真题语料库
