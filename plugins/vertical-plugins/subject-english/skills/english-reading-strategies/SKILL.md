# English Reading Strategies Skill

## 用途

把"阅读理解"从"凭感觉选"提升为"可训练、可复盘、可提升"的能力。

## 阅读策略清单

### 通用策略

| 策略 | 名称 | 适用 | 步骤 |
|---|---|---|---|
| Skimming | 略读 | 主旨题 | 看标题、首段、末段、首句 |
| Scanning | 扫读 | 细节题 | 找关键词，回原文定位 |
| Close Reading | 精读 | 推断题、词义题 | 逐句分析，上下文推理 |
| Predicting | 预测 | 推理题 | 根据线索预测下文 |
| Inferring | 推断 | 推断题 | 作者意图、情感、态度 |

### 文体策略

| 文体 | 特征 | 阅读重点 |
|---|---|---|
| 记叙文 | 时间、地点、人物、事件 | 5W1H、情节发展 |
| 说明文 | 总分总、定义、举例 | 主题句、举例处 |
| 议论文 | 论点、论据、论证 | 论点位置、论据类型 |
| 应用文 | 邮件、广告、通知 | 关键信息、收件人 |

### 题型策略

| 题型 | 策略 |
|---|---|
| 细节题 | 扫读找关键词 |
| 主旨题 | 略读找主题句 |
| 推断题 | 精读 + 推断 |
| 词义题 | 上下文 + 构词法 |
| 作者态度 | 高频词 + 立场词 |
| 标题题 | 主旨 + 情感 |

## 触发场景

- 阅读错题诊断
- 阅读专项训练
- 家长问"孩子阅读理解怎么练"

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| passage | ✅ | 文章（教材原文或自定义） |
| questions | ✅ | 配套题目 |
| student_answers | ❌ | 学生答案（用于诊断） |
| grade | ✅ | 年级 |

```markdown
- 策略：扫读

### q2（细节题，✗ 错）
- 题型：细节
- 错选：C
- 正确答案：A
- 错因：扫读时定位错
- 原文：第 2 段 "Reading improves memory, focus, and thinking skills."

### q3（主旨题，✓ 正确）

## 四、提升建议

### 基础动作
1. 每天 1 篇阅读（10 min）
2. 做题时**先标题型**（细节/主旨/推断）
3. 错题必**回原文定位**（不靠记忆）

### 策略训练
- 第 1 周：训练扫读（每篇 5 题细节题）
- 第 2 周：训练略读（每篇 3 道主旨题）
- 第 3 周：训练推断（每篇 2-3 道推断题）
- 第 4 周：综合训练

### 5 道变式题（基础 → 中等）
1. 基础：原文有明确答案
2. 中等：需要 1-2 句推断
3. 综合：需要 2-3 句推理

## 五、推荐阅读材料
- 教材 p.45-p.50 Reading 部分
- 21 世纪英语演讲稿（议论文）
- 教材配套 Reading Plus
```

```
  - location_error       # 扫读定位错
  - keyword_missed       # 漏掉关键词

  - attitude_unrecognized  # 漏态度词
  - vocabulary_blocked   # 词汇卡住
  - time_pressure        # 时间不够
  - careless             # 粗心
```

## 工作流

```
输入 (passage, questions, student_answers)
  ↓
1. 题目分类
   - 标记每题：细节/主旨/推断/词义
  ↓
2. 学生答题分析
   - 错题标记
   - 记录每题用时（如果有）
  ↓
3. 错因归类
   - 调误区库
   - 推断错因
  ↓
4. 策略回放
   - 标准解法步骤
   - 学生应改进的步骤
  ↓
5. 提升建议
   - 基础动作
   - 策略训练计划
  ↓
6. 变式题
   - 同类题 5 道
```

## 质量标准

- 错因诊断准确率 ≥ 80%
- 策略建议可执行
- 变式题难度递进
- 阅读材料基于教材或权威语料

## 护栏

1. **不评判学生**：不写"阅读能力差"
2. **不给"玄学"策略**：不写"多读就有语感"
3. **不超纲**：训练材料匹配年级
4. **不堆题**：每次 5 道变式就够
5. **不超时**：建议训练时间明确

## 不要做的事

- 不要把阅读讲成"理解作者的言外之意"
- 不要给"靠感觉"的策略
- 不要堆"长难句分析"（基础薄弱学生做不来）
- 不要直接给答案（用提问引导）
