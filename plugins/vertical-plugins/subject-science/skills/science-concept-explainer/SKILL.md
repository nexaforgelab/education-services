# Science Concept Explainer Skill

## 用途

把科学概念从"死记硬背"提升为"看得到现象、想得到原理、用得上公式"。

## 四层讲解

| 层级 | 名称 | 内容 | 面向 |
|---|---|---|---|
| L1 | 现象 | 生活现象、实验演示 | 全部学生 |
| L2 | 定性 | 概念定义、规律描述 | 中等学生 |
| L3 | 定量 | 公式、单位、计算 | 拔高学生 |
| L4 | 应用 | 生活应用、跨学科关联 | 拔高学生 |

## 触发场景

- 新概念授课
- 学生概念模糊
- 家长辅导
- 单元复习

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| concept | ✅ | 概念名 |
| subject | ✅ | physics / chemistry / biology / general |
| grade | ✅ | 年级 |
| textbook_id | ✅ | 教材 ID |
| chapter_id | ✅ | 章节 |
| audience | ✅ | teacher / parent / student |

## 输出

### 示例：牛顿第一定律（物理 八年级）

```markdown
# 牛顿第一定律

## L1 现象（家长能讲）

**想一想：**
- 推一下桌子，松手后桌子会怎样？（慢慢停下来）
- 为什么自行车刹车后会停？（摩擦力）
- 想象一个完全没有摩擦的冰面，推一下小球，会怎样？（永远不停）

**关键观察：** 物体运动不需要"力维持"，而是"力改变"运动状态。

## L2 定性（中等学生）

**定律内容：**
> 一切物体在没有受到外力作用时，总保持静止状态或匀速直线运动状态。

**关键词：**
- "没有受到外力"——理想条件
- "或"——两种可能：静止 或 匀速直线
- "总保持"——状态不变

**反例理解：**
- 静止的物体：不受力 → 保持静止
- 运动的物体：不受力 → 保持匀速直线
- 现实里没有"不受力"——所以总要"近似"理解

## L3 定量（拔高学生）

**公式形式：** 牛顿第一定律是定性定律，无数学公式
**但是：** 牛顿第二定律 F = ma 是它的"升级版"

**几个相关物理量：**
| 量 | 符号 | 单位 | 物理意义 |
|---|---|---|---|
| 力 | F | 牛（N） | 改变运动状态 |
| 质量 | m | 千克（kg） | 惯性大小 |
| 加速度 | a | m/s² | 运动状态变化率 |

**关系：**
- m 越大 → 惯性越大 → 越难改变运动状态
- F 越大 → 改变越快

## L4 应用

### 生活应用
- 汽车安全带：急刹车时人因惯性要前冲
- 拍打衣服：灰尘因惯性保持静止而脱落
- 跳远助跑：利用惯性继续前进

### 跨学科
- 哲学：运动是绝对的，静止是相对的
- 体育：惯性原理在投掷、跳跃中的应用
- 工程：缓冲设计（汽车、气囊）

## 常见错

❌ "物体运动需要力维持"——错
   - 真相：力是改变运动状态，不是维持运动
❌ "不受力的物体一定静止"——错
   - 真相：可能匀速直线运动
❌ "牛顿第一定律可以用实验直接验证"——错
   - 真相：现实中没有"不受力"条件，是理想定律

## 配套练习

### 基础
1. 静止的小车在光滑水平面上，会怎样？
2. 行驶的汽车关闭发动机后，会慢慢停下，为什么？

### 中等
3. 子弹从枪膛射出后能继续飞行，是什么在"推动"它？
4. 铁锤松了，把锤柄在石头上磕几下，为什么锤头会紧？

### 综合
5. 太空中的宇航员松手释放一个物体，物体会怎样？
6. 用牛顿第一定律解释"安全气囊"的工作原理。
```

## 质量标准

- L1 现象必须可观察
- L2 定义严格（不模糊）
- L3 公式准确
- L4 应用真实
- 100% 引用教材页码
- 常见错 80%+ 命中误区库

## 护栏

1. **科学准确**：不能有科学性错误
2. **不超纲**：不引入未学概念
3. **不简化失真**：简化不能导致科学性错误
4. **可验证**：现象必须可观察或可实验
5. **不夸大**：避免"玄学"式解释

## 不要做的事

- 不要把"简化"等同于"通俗"
- 不要在科学解释中加入伪科学
- 不要在 L1 用"不准确但好懂"的类比（科学性优先）
- 不要把"假说"当"定律"讲
- 不要在 L4 中加入价值观判断
