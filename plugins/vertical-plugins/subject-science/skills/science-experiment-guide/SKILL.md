# Science Experiment Guide Skill

## 用途

把"做实验"从"按步骤走"提升为"理解目的、观察现象、分析数据、得出结论"。

## 触发场景

- 实验课备课
- 学生写实验报告
- 中高考实验题复习
- 家长在家做小实验

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| experiment_name | ✅ | 实验名 |
| subject | ✅ | physics / chemistry / biology |
| grade | ✅ | 年级 |
| textbook_id | ✅ | 教材 ID |
| chapter_id | ✅ | 章节 |
| home_friendly | ❌ | 是否可在家做（默认 false） |

## 输出

### `experiment_guide.md`

```markdown
# 实验：探究液体内部压强与深度的关系

> 学科：物理 | 年级：八年级 | 教材 p.34-36
> 类型：探究实验
> 难度：★★★☆☆

## 一、实验目的

1. 探究液体内部压强与深度的定量关系
2. 学习使用压强计
3. 培养数据记录与分析能力

## 二、实验原理

- 液体内部压强公式：p = ρgh
  - p：压强（Pa）
  - ρ：液体密度（kg/m³）
  - g：重力加速度（9.8 N/kg）
  - h：深度（m）
- 猜想：深度越大，压强越大（线性关系）

## 三、实验器材

| 器材 | 数量 | 备注 |
|---|---|---|
| 压强计 | 1 | 透明容器 + U 形管 |
| 水 | 若干 | 自来水 |
| 盐 | 若干 | 用于改变密度 |
| 量筒 | 1 | 测量深度 |
| 刻度尺 | 1 | 备用 |

## 四、实验步骤

### 步骤 1：准备
1. 检查压强计气密性
2. U 形管两侧液面是否平齐
3. 记录初始读数

### 步骤 2：测不同深度
1. 将压强计金属盒放入水中
2. 改变深度：5 cm → 10 cm → 15 cm → 20 cm
3. 每个深度记录 U 形管液面高度差
4. 重复 3 次取平均

### 步骤 3：改变液体
1. 用盐水代替水
2. 同样测 4 个深度
3. 记录数据

### 步骤 4：整理
1. 关闭电源（如有）
2. 擦干器材
3. 数据记录到表格

## 五、数据记录表

| 深度 h (cm) | 水 高度差 Δh₁ (cm) | 盐水 高度差 Δh₂ (cm) |
|---|---|---|
| 5  |  |  |
| 10 |  |  |
| 15 |  |  |
| 20 |  |  |

## 六、预期现象

- 水：随深度增加，U 形管高度差线性增加
- 盐水：相同深度下，高度差更大（密度大 → 压强大）

## 七、结果分析

### 数据处理
1. 画 p-h 关系图
2. 拟合直线，求斜率
3. 斜率 = ρg → 验证猜想

### 误差分析
- 来源 1：金属盒放入水中时液面变化
- 来源 2：U 形管读数误差（±1 mm）
- 来源 3：水温变化（影响密度）

## 八、实验结论

1. 同种液体中，深度越深，压强越大
2. 压强与深度成正比（线性关系）
3. 不同液体，密度越大，相同深度的压强越大

## 九、注意事项

⚠️ 安全
- 压强计小心使用，避免摔坏
- 玻璃 U 形管破损勿用手直接触碰

⚠️ 操作
- 金属盒放入水中要轻放，避免冲击
- 每次读数前稳定 5 秒
- 金属盒不能触底

## 十、思考题

1. 如果把金属盒侧放，结果会不同吗？
2. 同一深度，金属盒朝向不同方向，压强是否相同？
3. 压强计在密闭容器中和开放容器中读数会不同吗？

## 十一、家长可在家做的小实验

如果不能去实验室，可做简化版：

**材料**：透明玻璃杯 + 水 + 多个相同小孔的塑料瓶
**步骤**：
1. 在塑料瓶壁上不同高度各扎一个小孔（用针）
2. 装满水
3. 观察：哪个孔射出的水最远？
4. 答案：越靠下，水流越远（压强越大）

**原理**：用"水流远近"代替"压强计"，直观演示深度与压强的关系。
```

## 物理实验分类

### 测量类

| 实验 | 测量量 | 工具 |
|---|---|---|
| 长度测量 | 长度 | 刻度尺 / 游标卡尺 / 螺旋测微器 |
| 时间测量 | 时间 | 秒表 / 打点计时器 |
| 质量测量 | 质量 | 天平 |
| 力测量 | 力 | 弹簧测力计 |
| 电流测量 | 电流 | 电流表 |
| 电压测量 | 电压 | 电压表 |

### 探究类

| 实验 | 探究变量 |
|---|---|
| 牛顿第二定律 | F / m / a 关系 |
| 欧姆定律 | U / I / R 关系 |
| 液体压强 | 深度 / 密度 / 压强 |
| 浮力 | 排开液体 / 浮力 |

| 实验 | 验证目标 |
|---|---|
| 机械能守恒 | 动能 + 势能 = 恒定 |
| 玻意耳定律 | PV = 恒定 |

## 质量标准

- 步骤清晰可执行
- 数据记录表完整
- 误差分析具体
- 思考题有引导
- 家长版简化版可在家做

## 护栏

1. **安全第一**：所有化学实验标安全警示
2. **不删步骤**：所有步骤必须执行到位
3. **数据真实**：不编造数据
4. **可重复**：步骤可让其他学生重复
5. **不超纲**：实验难度匹配年级
6. **可简化**：可提供"在家版"

## 不要做的事

- 不要把"危险实验"推荐给家长在家做
- 不要在步骤中省略关键细节
- 不要给"理论数据"代替"实际测量"
- 不要在误差分析中只写"误差很小"
- 不要把"验证性实验"说成"探究性实验"
