# Science Misconception Diagnoser Skill

## 用途

沉淀科学（物理/化学/生物）学科的 **误区库**——把"这道题做错了"提升为"学生卡在哪个科学概念"。

## 物理典型误区

### 力学

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 物体运动需要力维持 | "推桌子要用力，停手就不动了" | 力是改变运动状态，不是维持 |
| 重力=质量 | "我 50 kg，所以重力是 50 N" | 重力单位是 N，质量单位是 kg |
| 重的物体下落快 | "铁球比木球下落快" | 同一高度，忽略空气阻力时同时落地 |
| 静止物体不受力 | "桌子不动，所以没受力" | 桌子受重力和支持力，平衡 |
| 惯性是力 | "汽车急刹车时受到惯性力" | 惯性是属性，不是力 |
| 浮力=物体重量 | "沉底的石头没浮力" | 浮力看是否排开液体，与沉浮无关 |
| 速度=加速度 | "速度大加速度就大" | 加速度是速度变化率 |

### 电学

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 电流被"用光" | "灯泡用完电后电流变小" | 电流在回路中是相同的 |
| 电压=电流 | "电压大电流就大" | 还和电阻有关（U=IR） |
| 电池有正负电荷 | "电池里有正电和负电" | 电池驱动电荷定向移动 |
| 接地无电流 | "接地了所以没电流" | 接地是安全保护，不是断路 |

### 光学

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 看见=有光 | "黑暗中也可能有光，只是看不见" | 看见是反射光进入眼睛 |
| 影子=黑色 | "影子是物体本身的黑色" | 影子是光被遮挡的区域 |
| 凸透镜成实像 | "凸透镜总是成实像" | 取决于物距 |

### 热学

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 温度=热量 | "100°C 水比 50°C 水热量多" | 温度是强度，热量是能量 |
| 冰是 0°C | "冰一定是 0°C" | 冰可以是 -10°C |

## 化学典型误区

### 物质构成

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 分子 = 原子 | "分子比原子大" | 分子由原子组成，大小不可比 |
| 元素 vs 物质 | "铁元素是一种物质" | 元素是类别，物质是具体物 |
| 同位素是不同元素 | "C-12 和 C-14 是不同元素" | 同位素是同元素不同原子 |

### 化学反应

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 催化剂参与反应 | "催化剂是反应物" | 催化剂参与中间过程，但最终不变 |
| 质量不守恒 | "蜡烛燃烧变轻，所以质量减少" | 加上气体产物总质量守恒 |
| 复分解 = 互换 | "AB + CD = AD + CB 总是" | 还要满足条件（生成气体/沉淀/水） |

### 酸碱盐

| 误区 | 学生表现 | 真相 |
|---|---|---|
| pH = 7 一定中性 | "pH=7 一定中性" | 25°C 时 pH=7 中性，其他温度不一定 |
| 酸溶液一定有酸味 | "酸一定有酸味" | 不一定（如 HCl 无味） |

## 生物典型误区

### 细胞

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 植物细胞有叶绿体 | "所有植物细胞都有叶绿体" | 根细胞无叶绿体 |
| DNA 在细胞核外 | "DNA 在细胞质" | 主要在细胞核 |

### 生理

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 光合作用只在白天 | "光合作用只在白天进行" | 暗反应也可在短时间内进行 |
| 呼吸是肺的活动 | "呼吸就是肺" | 呼吸是细胞层面的反应 |
| 心脏泵血只走一个方向 | "心脏一收一放，血就出去又回来" | 有瓣膜保证单向 |

### 生态

| 误区 | 学生表现 | 真相 |
|---|---|---|
| 食物链 = 食物网 | "森林里就是 3 条食物链" | 实际是错综复杂的网 |
| 能量是循环的 | "能量在生态系统中循环" | 能量单向流动，物质循环 |

## 误区库结构

```yaml
# misconceptions.yaml
- id: MIS-PHY-8-001
  subject: physics
  grade: 8
  chapter: 力与运动
  concept: 牛顿第一定律
  misconception: 物体运动需要力维持
  detection_pattern:
    - "推桌子停手就不动了"
    - "汽车发动才有速度"
  correct_concept: 力是改变运动状态，不是维持运动
  remediation:
    analogy: "想象光滑冰面，推一下小球——没有摩擦，永远不停"
    socratic_questions:
      - "如果完全没摩擦，会停吗？"
      - "是什么让物体停下来？"
  page_refs: [ch08_s01_p34]
  severity: high
```

## 工作流

```
错题 + 学生答案
  ↓
1. 题目解析
   - 提取考点
   - 识别正确解法
  ↓
2. 误区匹配
   - 比对误区库
   - 计算匹配分
  ↓
3. 误区命中
   - 命中 → 复用解释
   - 未命中 → 通用分析
  ↓
4. 严重度评估
   - high: 核心概念错
   - medium: 单点错
   - low: 粗心
  ↓
5. 补救方案
   - 类比
   - 苏格拉底问题
   - 变式练习
```

## 实现要点

```python
def diagnose_science_error(problem, student_answer, correct_answer, subject, grade):
    parsed = parse_problem(problem)
    matches = search_misconceptions(subject=subject, grade=grade, pattern=parsed.pattern)
    
    if matches:
        return MisconceptionResult(
            matched=True,
            misconception=matches[0],
            remediation=matches[0].remediation
        )
    else:
        return MisconceptionResult(matched=False, error_type=parsed.error_type)
```

## 质量标准

- 误区库 ≥ 200 条（每学科每年级 20+）
- 识别准确率 ≥ 80%
- 补救方案基于科学

## 护栏

1. **科学准确**：纠正后的概念必须科学
2. **不简化失真**：简化不能导致科学错误
3. **不夸大误区**：常见错误不一定是误区
4. **不羞辱**：写"误区"是教学术语
5. **不歧视**：避免文化敏感话题

## 不要做的事

- 不要把"误区"和"粗心"混为一谈
- 不要在纠正中用"完全错误"这种话
- 不要用"伪科学"举例
- 不要在解释中加入"政治"内容
