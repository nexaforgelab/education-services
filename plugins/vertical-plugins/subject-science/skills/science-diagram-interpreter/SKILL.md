# Science Diagram Interpreter Skill

## 用途

把"科学图表"从"看不懂"提升为"会画、会看、会分析"。

## 图表分类

| 类别 | 典型 | 学科 |
|---|---|---|
| 受力图 | 力的示意图 | 物理 |
| 电路图 | 串并联电路 | 物理 |
| 光路图 | 反射/折射 | 物理 |
| 装置图 | 实验装置 | 物理/化学/生物 |
| 坐标图 | s-t / v-t / p-V | 物理/化学 |
| 流程图 | 工艺流程 | 化学 |
| 概念图 | 知识结构 | 生物 |
| 显微图 | 细胞结构 | 生物 |

## 触发场景

- 题目含图
- 学生看不懂图
- 错题涉及图

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| diagram_type | ✅ | 图类型 |
| diagram_url | ✅ | 图 URL 或 base64 |
| question | ✅ | 配套题目 |
| grade | ✅ | 年级 |
| subject | ✅ | 学科 |

## 输出

### `diagram_analysis.md`

```markdown
# 图表解读：电路图

> 学科：物理 | 年级：九年级 | 图类型：电路图

## 一、图表识别

- 电源：1 节干电池（电压 1.5 V）
- 开关：S
- 电阻：R₁ = 10Ω，R₂ = 20Ω
- 电流表：A
- 电压表：V
- 连接方式：R₁ 与 R₂ **并联**

## 二、图表标注（解读步骤）

### Step 1：识别元件
- 用不同符号表示元件
- 注意：长线为正极（电源）、短线为负极

### Step 2：判断连接方式
- 看节点：电流从一点出发能走几条路
- 单路 → 串联
- 多路 → 并联

### Step 3：分析电表测量对象
- 电流表 A：与 R₂ 串联 → 测 R₂ 电流
- 电压表 V：与 R₁ 并联 → 测 R₁ 电压

## 三、配套题目

### 题：闭合 S 后，电流表 A 和电压表 V 的读数
**解析**：
- 电流表测 R₂：I = U/R₂ = 1.5/20 = 0.075 A
- 电压表测 R₁：U_R₁ = 1.5 V（并联等压）
- 答案：A = 0.075 A，V = 1.5 V

## 四、常见错误

❌ 看错连接方式
- 错：把并联看成串联
- 对：仔细看节点

❌ 错认电表测量对象
- 错：以为电流表测干路
- 对：电表与谁串联/并联就测谁

❌ 单位混淆
- 错：电流表读数 75
- 对：0.075 A（注意量程）

## 五、画图方法

### 画电路图步骤
1. 画电源（标正负极）
2. 画开关（与电源串联）
3. 画用电器（按连接方式）
4. 画电表（与被测元件对应）
5. 用导线连接，检查回路

### 注意事项
- 元件符号要规范
- 导线要横平竖直
- 不能有"短线"（未连接的线）

## 六、配套练习
（5 道电路图分析题）
```

## 各图类型解读要点

### 受力分析图

**基本步骤**：
1. 选定研究对象（隔离体）
2. 画出重力
3. 找出接触面 / 接触点
4. 画支持力、摩擦力（如果有）
5. 画其他外力
6. 检查：每个力都画了吗？有"漏力"或"多力"吗？

**常见错**：
- 漏掉摩擦力
- 力的方向画反
- 多个物体没隔离分析

### 电路图

**基本步骤**：
1. 识别电源（正负极）
2. 识别用电器
3. 判断连接方式
4. 识别电表测量对象
5. 列方程（欧姆定律）

**关键标志**：
- 串联：元件首尾相接
- 并联：元件两端分别相连

### 光路图

**反射定律**：
- 反射光线、入射光线、法线在同一平面
- 反射角 = 入射角
- 反射光线、入射光线在法线两侧

**折射定律**：
- 折射光线、入射光线、法线在同一平面
- 折射光线、入射光线在法线两侧
- 角度关系：n₁ sin θ₁ = n₂ sin θ₂

**凸透镜成像规律**：

| 物距 u | 像距 v | 像的性质 |
|---|---|---|
| u > 2f | f < v < 2f | 倒立缩小实像 |
| u = 2f | v = 2f | 倒立等大实像 |
| f < u < 2f | v > 2f | 倒立放大实像 |
| u = f | 不成像（平行光） | |
| u < f | 虚像 | 正立放大虚像（同侧） |

### 坐标图

**s-t 图（位移-时间）**：
- 斜率 = 速度
- 直线 = 匀速
- 曲线 = 变速

**v-t 图（速度-时间）**：
- 斜率 = 加速度
- 面积 = 位移

**p-V 图（压强-体积）**：
- 等温线：双曲线
- 面积 = 功

### 化学图像

**反应能量图**：
- 纵轴：能量
- 横轴：反应进程
- 峰：活化能
- 起点到终点：吸热 / 放热

**溶解度曲线**：
- 上升：大多数固体（温度升高溶解度增大）
- 下降：少数固体（Ca(OH)₂）
- 注意交点：不同物质同一温度下溶解度相同

### 流程图（化学/生物）

**阅读步骤**：
1. 从左到右 / 从上到下
2. 识别每一步操作
3. 找出关键节点
4. 写出各步的化学/生物变化

## 工作流

```
输入 (diagram, question)
  ↓
1. 图表识别

  ↓
3. 配套题目解答
  ↓
4. 常见错误
  ↓
5. 画图方法
  ↓
6. 配套练习
```

## 质量标准

- 解读步骤清晰
- 配套题目解答详细
- 常见错误完整
- 画图方法可操作

## 护栏

1. **科学准确**：解读不能错
2. **不超纲**：匹配年级
3. **不替代学生**：画图方法只给步骤，不代画

## 不要做的事

- 不要替学生完成受力分析
- 不要在电路图中加"魔法元件"
- 不要在坐标图中错标物理量
- 不要用"模糊"语言描述图
- 不要跳过中间步骤
