# Pedagogy Method Skill

## 用途

不是"教学方法百科全书"，而是 **决策器**：给定 (学生水平、知识点类型、教学目标)，输出"用哪种方法 + 怎么执行"。

## 决策矩阵

| 知识点类型 | 学生水平 | 推荐策略 |
|---|---|---|
| 抽象概念 | 基础薄弱 | 类比 + 图像化 + 多例 |
| 抽象概念 | 中等 | 启发式 + 提问链 |
| 抽象概念 | 拔高 | 探究 + 反例 + 推广 |
| 程序性 | 基础薄弱 | 示范 + 模仿 + 步骤化 |
| 程序性 | 中等 | 变式练习 + 互评 |
| 程序性 | 拔高 | 优化 + 一题多解 |
| 应用题 | 基础薄弱 | 画图 + 列式模板 |
| 应用题 | 中等 | 建模 + 反思 |
| 应用题 | 拔高 | 多解 + 推广 |
| 概念辨析 | 全部 | 反例 + 对比 + 分类 |

```json
  "topic": "有理数加法-异号",
  "student_level": "中等",
  "recommended_strategy": "启发式",
  "rationale": "异号相加规则需要符号判定+绝对值比较，适合通过问题链引导学生自己发现",
  "execution": {

    "phases": [

      { "phase": "归纳", "min": 5, "activity": "学生自己总结口诀" },
      { "phase": "练习", "min": 5, "activity": "3 道分层题" }

    "key_questions": [

  ]

```

## 护栏

1. 不写空话（"启发思维"）
2. 必给具体可执行步骤
3. 必给"如果不行"的备选方案
4. 标注理论依据（如"基于维果茨基最近发展区"）

## 风格

简明、可操作、教师看完就能用。
