# Citation Policy Skill

## 用途

教育 Agent 的"引用铁律"——所有教材相关结论必须能追溯到具体位置。

**为什么这是底线**：教师/家长拿到 Agent 输出后，最关心的就是"教材上是不是这么说的"。

## 引用铁律

### 必须引用的内容

- 教材原文定义
- 教材例题、公式、定理
- 教材章节小结
- 教材"想一想"、"议一议"、"注意"中的关键观点

### 引用格式

```
《{title}》{version}，第 {chapter} 章 {section} 节，第 {page} 页
```

示例：
- `《数学 七年级 上册》人教版，第 1 章第 1 节，第 2 页`
- `《数学 七年级 上册》人教版，第 1 章第 1 节，第 2 页，例 1`
- `《数学 七年级 上册》人教版，第 1 章复习题，第 30 页，习题 1.3 第 5 题`

### 置信度标签

| 标签 | 含义 | 示例 |
|---|---|---|
| `[教材原文]` | 直接引用教材 | "正数是大于 0 的数 `[教材原文 p.2]`" |
| `[教材衍生]` | 教材内容的基础上做的解释 | "用数轴理解正负数 `[教材衍生]`" |
| `[课程标准]` | 来自课程标准推断 | "理解相反意义的量 `[课程标准 2022]`" |
| `[通用知识]` | 通用教育/学科知识 | "分数先通分 `[通用知识]`" |
| `[教材未找到依据]` | 教材没有直接依据 | "异号相加时符号的由来 `[教材未找到依据]`，一般教材在 X 章补充说明" |

## 工作流

```
生成输出
  ↓
1. 标定每条教材相关结论
   - 是否有页码/章节依据？
   - 有 → 标 [教材原文] 或 [教材衍生]
   - 无 → 标 [教材未找到依据] 或 [通用知识]
  ↓
2. 不得编造
   - 不允许写"教材上写 ..."
   - 不允许把通用知识伪装成教材内容
  ↓
3. 输出时统一格式
   - 引用内联，不放脚注（教师/家长不爱翻脚注）
   - 列表化展示关键引用
  ↓
4. 最终检查清单
   - [ ] 所有 [教材原文] 都标了页码
   - [ ] 没有 [教材未找到依据] 的内容伪装成教材
   - [ ] 没有"教材上明确说 ..."这种没出处的表述
```

## 反例（绝对不要）

❌ "教材上明确说，异号两数相加取绝对值较大的符号"
   - 没有页码

❌ "人教版教材认为，减负数等于加正数"
   - 错误归属（人教版没有"认为"）

❌ "教材中提到，对数计算要先换底"
   - 编造（教材中无此话）

## 正例

✅ "教材 p.18 指出：'减去一个数，等于加上这个数的相反数'"

✅ "异号两数相加的符号规则（教材 p.20）"

✅ "对于这一点，教材中没有直接说明，但根据课程标准'理解有理数运算'，可推断 ..."

## 护栏

1. **不编造**：宁可标 [教材未找到依据] 也不编页码
2. **不模糊**：不写"教材大概说 ..."，必须精确
3. **不堆引用**：正文流中关键 2-3 处即可，列表中可全列
4. **不同版本**：标清版本（人教版 / 北师大版）
5. **可追溯**：教师/家长可随时翻到对应页码验证

## 故障处理

| 情况 | 处理 |
|---|---|
| 教材 PDF 缺失 | 标 [课程标准] 或 [通用知识]，明确告诉用户 |
| 教材扫描不清 | 标 [教材未找到依据]，并提示用户提供清晰版本 |
| 多版本差异 | 标出"人教版如此，北师大版如此" |
| 用户质疑引用 | 立刻提供页码截图（若 PDF 可访问） |
