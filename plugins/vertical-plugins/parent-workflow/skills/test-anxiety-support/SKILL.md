# Test Anxiety Support Skill

## 用途

把"考试焦虑"从"靠鸡汤"提升为"按阶段、按角色、按方法"的可操作支持。

## 触发场景

- 考试前孩子紧张
- 考试中大脑空白
- 考试后情绪崩溃
- 家长自己也焦虑

## 识别考试焦虑

### 生理信号

| 信号 | 表现 |
|---|---|
| 失眠 | 考前 1-2 天睡不着 |
| 食欲差 | 吃不下 / 吃多了 |
| 心跳快 | 莫名心慌 |
| 出汗 | 手心出汗 |
| 肚子不舒服 | 拉肚子 / 胃痛 |
| 头晕 / 乏力 | 身体疲劳感 |

### 情绪信号

| 信号 | 表现 |
|---|---|
| 易怒 | 一点小事就发火 |
| 哭泣 | 无端想哭 |
| 紧张 | 担心"考砸" |
| 绝望 | "完了完了" |
| 害怕 | "我不想去考试" |

### 认知信号

| 信号 | 表现 |
|---|---|
| 灾难化 | "考砸了就完了" |
| 完美主义 | "我必须考 100 分" |
| 灾难预测 | "我肯定考不好" |
| 思维卡住 | "我什么都想不起来了" |

### 行为信号

| 信号 | 表现 |
|---|---|
| 逃避 | "我不考了" |
| 拖延 | 拖到考试前一刻才复习 |
| 反复检查 | 检查书包 3 次 |
| 寻求安慰 | 反复问家长"我能行吗" |

## 三阶段应对

### 考前 1-2 周

#### 家长能做

- 调整期待：明确告诉孩子"尽力就好"
- 减少压力：不天天说考试
- 帮助准备：一起整理复习计划
- 保证休息：不过度复习
- 模拟考试：1-2 次小测找感觉

#### 家长不要做

- ❌ "这次必须考 90 分"
- ❌ "考不好就完了"
- ❌ 天天念叨"复习了吗"
- ❌ 拿别人家孩子比较
- ❌ 自己比孩子还焦虑

#### 孩子能做

- 制定复习计划
- 每天 30 min 运动
- 充足睡眠（8-9 小时）
- 饮食均衡
- 准备考试用品（提前 3 天）

### 考前 1 天

#### 家长

- 营造轻松氛围：散步、看电影、做游戏
- 不讨论考试
- 帮助准备：准考证、笔、橡皮
- 早睡（22:00 前）
- 准备第二天早餐

#### 孩子

- 不再做新题
- 翻看错题本（仅 30 min）
- 早睡
- 准备好考试用品

### 考试当天

#### 考前（出门前）

- **家长话术**：
  - "今天天气不错，去考试吧"
  - "你昨晚复习得挺扎实的"
  - "记得带准考证和笔"
  - **不要**："加油！一定要考好！"

- **孩子**：
  - 早餐：碳水 + 蛋白（不要过饱）
  - 提前 15 min 到考场
  - 进场前做 3 次深呼吸

#### 考中

- **遇到不会的题**：
  1. 跳过，先做会的
  2. 深呼吸 3 次
  3. 回忆相关知识点
  4. 实在不会就放下，最后回来

- **大脑空白**：
  1. 闭眼 5 秒
  2. 慢慢吸气 4 秒
  3. 屏住 4 秒
  4. 慢慢呼气 4 秒
  5. 重复 3 次
  6. 重新读题

- **时间不够**：
  1. 标记得分最高但没做的题
  2. 先做这些
  3. 其余用关键词列要点

#### 考后

- **家长话术**：
  - "考完了，咱们去吃好吃的"
  - "不管考得怎样，你已经尽力了"
  - **不要**："考得怎么样？"（立即问）
  - **不要**："能考多少分？"
  - **不要**："这么简单你怎么还错了"

- **孩子**：
  - 不立即对答案
  - 适当休息 / 运动
  - 等成绩出来再说

## 焦虑应对技巧

### 1. 深呼吸（4-7-8 法）

1. 吸气 4 秒
2. 屏住 7 秒
3. 呼气 8 秒
4. 重复 3-4 次

### 2. 渐进式肌肉放松

从头到脚，每组肌肉：
1. 紧绷 5 秒
2. 放松 10 秒
3. 感受差异

### 3. 正念冥想（5 分钟）

1. 坐直，闭眼
2. 关注呼吸
3. 杂念来了，让它走
4. 拉回注意力

### 4. 认知重构

把"考砸了"换成：
- "一次考试不代表什么"
- "我准备得挺充分"
- "最坏的结果也能接受"
- "还有很多次机会"

## 何时寻求专业帮助

### 信号

- 每周 ≥ 3 次噩梦
- 完全无法学习
- 失眠 1 周以上
- 出现自伤念头
- 惊恐发作（心慌、胸闷、濒死感）

### 资源

- 学校心理老师
- 心理咨询热线：12355（青少年）
- 三甲医院心理科
- 青少年心理健康中心

## 家长自己焦虑怎么办

### 家长焦虑的信号

- 自己失眠
- 比孩子还紧张
- 忍不住催促
- 忍不住对比别人家孩子

### 应对

- 接受"适度焦虑"是正常的
- 与伴侣 / 朋友倾诉
- 不把自己的焦虑传递给孩子
- 必要时寻求心理咨询

## 长期建议

### 培养"成长型思维"

| ❌ 固定型 | ✓ 成长型 |
|---|---|
| "我笨" | "我还没学会" |
| "考砸了" | "一次考试而已" |
| "比别人差" | "我和上周比" |
| "我不行" | "我可以努力" |

### 培养学习能力 > 关注分数

- 关注"如何学"而不是"考几分"
- 关注"理解"而不是"答案"
- 关注"努力"而不是"聪明"

## 护栏

1. **不诊断**：不写"孩子焦虑症"
2. **不替代专业**：严重情况建议转介
3. **不传焦虑**：家长管好自己的情绪
4. **不强调分数**：淡化分数重要性
5. **不比较**：每个孩子节奏不同
6. **不忽视**：严重情况必须重视

## 不要做的事

- 不要说"考不好就完了"
- 不要天天问"复习了吗"
- 不要拿别人家孩子比
- 不要传递自己的焦虑
- 不要把考试当"家庭大事"
- 不要因一次考砸全盘否定
