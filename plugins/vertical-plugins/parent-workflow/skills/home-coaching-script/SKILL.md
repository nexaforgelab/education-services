# Home Coaching Script Skill

## 用途

把"教研方案"翻译成"家长今晚 10 分钟就能用的辅导脚本"。

## 脚本结构

```markdown
# 今晚 10 分钟：xxx

> 适合：xxx
> 主题：xxx
> 核心：xxx

## 0. 准备（1 min）
- 关掉电视
- 准备草稿纸 + 笔
- 准备水
- 让孩子先看 2 分钟教材

## 1. 聊一聊（2 min）
> 家长话术："今天数学学了什么新内容？"
> 家长话术："你觉得最难的是哪一步？"
> 家长话术："老师讲的哪个例子你印象最深？"
（注意：先听孩子讲，不打断，不评判）

## 2. 解释一下（2 min）
> 家长话术（照念）："我们今天一起看一下 ... ..."
（用 parent-friendly-explanation 的"家长语言"）

## 3. 一起做（3 min）
- 3 道小练习（基础 → 中等 → 综合）
- 不直接给答案
- 孩子卡住时用"提示阶梯"：

### 提示阶梯
1. 第一次卡：读题
2. 还卡：画图 / 列表
3. 还卡：问"学过什么方法"
4. 还卡：问"已知什么、求什么"
5. 还卡：家长示范第一步
（不要一步到位给答案）

## 4. 检查理解（1 min）
> 家长话术："你能跟我讲一遍这道题吗？"
> 家长话术："如果换个数字，你会怎么做？"
（如果讲不出来，说明没真懂，明天再练）

## 5. 鼓励（1 min）
> "今天 [具体表扬] ..."
> "明天我们继续 ..."
（不空泛、不和别人比）
```

## 提示阶梯原则

| 层级 | 提示类型 | 何时用 |
|---|---|---|
| 0 | 让孩子自己再读一遍 | 第一次卡住 |
| 1 | 提示"已知什么、求什么" | 还卡 |
| 2 | 提示"画图、列表" | 还卡 |
| 3 | 提示"学过什么方法" | 还卡 |
| 4 | 示范第一步 | 实在卡 |
| ❌ | 直接给答案 | 永不 |

## 质量标准

- 家长能照本宣科
- 提示阶梯清晰
- 鼓励具体不空泛
- 10 分钟内能完成
- 不评判孩子
