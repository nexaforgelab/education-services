# Study Habit Builder Skill

## 用途

把"好习惯"从"靠自律"提升为"按科学、按阶段、按方法"的系统工程。

## 触发场景

- 家长说"孩子没养成好习惯"
- 学期初 / 新年级
- 学习状态差
- 专注力不足

## 习惯科学基础

### 21 天 vs 66 天 vs 254 天

| 阶段 | 时长 | 行为 |
|---|---|---|
| 1-7 天 | 强烈抗拒 | 需要外部提醒 |
| 7-21 天 | 初步养成 | 需要意志力 |
| 21-66 天 | 行为固化 | 偶尔松懈 |
| 66-254 天 | 真正习惯 | 自动执行 |

→ **所以"21 天养成"是误区**，习惯需要 **2-9 个月** 才能真正稳定。

### 习惯回路

```
提示（cue）→ 渴求（craving）→ 反应（response）→ 奖励（reward）
```

要让一个新习惯稳固：
1. **明显提示**（固定时间、固定地点）
2. **强烈渴求**（把习惯和情绪连接）
3. **简单反应**（一开始不要做太多）
4. **即时奖励**（完成后给个小奖励）

## 关键学习习惯清单

### 1. 预习

| 维度 | 标准做法 |
|---|---|
| 时机 | 写作业前 / 睡觉前 |
| 时长 | 10-15 min |
| 内容 | 看 1-2 遍教材 + 标疑问 |
| 工具 | 便利贴 / 笔记 |

**家长话术**：
> "你看看明天要学什么，把不懂的标出来，明天重点听。"

### 2. 听课

| 维度 | 标准做法 |
|---|---|
| 状态 | 精神集中 |
| 笔记 | 关键句 + 公式 + 例题 |
| 互动 | 主动提问 |
| 工具 | 笔记本 |

**家长话术**：
> "今天哪道题最有趣？"

### 3. 复习

| 维度 | 标准做法 |
|---|---|
| 时机 | 当天 / 周末 |
| 时长 | 15-30 min |
| 方法 | 复述 / 默写 / 思维导图 |
| 频率 | 艾宾浩斯：1 / 2 / 4 / 7 / 15 天 |

**艾宾浩斯曲线**：

| 时间 | 记忆留存 |
|---|---|
| 20 min | 58% |
| 1 hour | 44% |
| 1 day | 34% |
| 2 days | 28% |
| 6 days | 25% |
| 31 days | 21% |

→ 复习要在 1 天内完成第一次！

### 4. 作业

| 维度 | 标准做法 |
|---|---|
| 时机 | 放学回家 30 min 后 |
| 时长 | 1-1.5 小时 |
| 顺序 | 难 → 易？or 易 → 难？ |
| 检查 | 完成后必自查 |
| 工具 | 计时器 / 番茄钟 |

**作业顺序争议**：
- 难的先做：挑战驱动
- 易的先做：建立信心

**推荐**：先易后难，每完成一项有成就感。

### 5. 错题本

| 维度 | 标准做法 |
|---|---|
| 格式 | 原题 / 错解 / 正解 / 错因 / 同类 |
| 频率 | 当天 / 周末整理 |
| 复习 | 周末看一遍 |
| 工具 | 活页本 / Notion |

**错题本模板**：

```
原题：___________________
错解：___________________
正解：___________________
错因：□ 概念 □ 计算 □ 审题 □ 方法 □ 步骤
同类题：___________________
日期：_______
```

### 6. 时间管理

| 维度 | 标准做法 |
|---|---|
| 工具 | 番茄钟 / 清单 |
| 计划 | 每天 3 件必做 |
| 复盘 | 睡前 5 min |
| 调整 | 周末调计划 |

### 7. 阅读

| 维度 | 标准做法 |
|---|---|
| 时长 | 每天 20-30 min |
| 选书 | 兴趣优先 + 老师推荐 |
| 笔记 | 好词好句 / 感想 |
| 分享 | 与家长交流 |

## 分龄重点

### 小学低年级（1-3）

- **重点**：坐得住 + 按时完成 + 握笔姿势
- **不要**：刷题 / 排名
- **家长**：陪写 + 培养习惯

### 小学高年级（4-6）

- **重点**：独立完成 + 错题本 + 时间管理
- **不要**：陪写 / 替检查
- **家长**：监督 + 鼓励

### 初中（7-9）

- **重点**：自主学习 + 学科平衡 + 难点突破
- **不要**：完全放手
- **家长**：陪伴 + 建议

### 高中（10-12）

- **重点**：学科取舍 + 效率 + 应试
- **不要**：事事过问
- **家长**：支持 + 资源

## 习惯培养 4 步法

### Step 1: 选习惯（1 个）

- 不要一次培养 5 个习惯
- 一次只选 1 个
- 选"最小可行习惯"（5 min 就能做）

### Step 2: 设提示

- 固定时间：每天 19:00 看错题
- 固定地点：书桌
- 固定触发：晚饭后 → 书桌 → 错题本

### Step 3: 给奖励

- 即时奖励：每完成 1 周买个小文具
- 中期奖励：1 个月去公园
- 长期奖励：学期末家庭旅行

### Step 4: 跟踪

- 打卡表（贴墙上）
- 全家可见（不强迫，是鼓励）
- 不打卡 = 重新开始

## 常见坏习惯纠正

### 写作业拖拖拉拉

```
诊断：
- 不会做？
- 不愿做？
- 想做但坐不住？
- 有干扰？

对策：
- 不会 → 家长辅助理解
- 不愿 → 沟通 + 小奖励
- 坐不住 → 番茄钟
- 干扰 → 移走手机 / 关电视
```

### 边写边玩

```
诊断：
- 注意力问题？
- 任务太难？
- 任务太简单？

对策：
- 注意力 → 番茄钟 + 休息
- 太难 → 拆小任务
- 太简单 → 提高要求
```

### 不复习

```
诊断：
- 不知道复习什么？
- 不会复习？
- 懒得复习？

对策：
- 不会 → 教他方法（思维导图）
- 懒得 → 让复习成为习惯
- 不知道 → 错题本是入口
```

## 家长话术模板

### 表扬习惯

> "你今天主动写完了作业，没让我催。"
> "你这次复盘得很认真。"
> "我发现你做应用题前先画图了，这个习惯很好。"

### 提示习惯（不评判）

> "今天复习了吗？"
> "错题本整理了吗？"
> "下周有什么打算？"

### 引导反思

> "今天做得好的是什么？"
> "明天想改什么？"
> "我们一起想想怎么改？"

## 21 天 / 66 天 / 254 天计划示例

### 习惯：每天 10 分钟阅读

| 阶段 | 目标 | 奖励 |
|---|---|---|
| 1-7 天 | 每天 10 min | 每天小贴纸 |
| 8-21 天 | 每天 10 min | 周末去书店 |
| 22-66 天 | 每天 10-15 min | 月底家庭看电影 |
| 67-254 天 | 自由时间 + 笔记 | 学期末买新书 |

## 护栏

1. **不强制**：避免引发对抗
2. **不替代**：家长不能替孩子养成
3. **不焦虑**：1-2 周没变化是正常的
4. **不放弃**：习惯需要时间
5. **不忽视**：超过 3 个月没变化需要反思

## 不要做的事

- 不要一次性培养 5 个习惯
- 不要用物质奖励过度（破坏内在动机）
- 不要因一次没做到全盘否定
- 不要把孩子的习惯问题归因于性格
- 不要在情绪激动时讨论习惯
