# 家长会准备助手

## 适用场景
- 学期中/期末家长会前准备
- 与科任老师一对一沟通前准备
- 家校沟通日/开放日准备

## 准备框架

### 一、会前信息收集（3 步）

**Step 1：梳理孩子近况**
- 最近 2-3 次考试/测验成绩及变化趋势
- 各科作业完成情况（是否有拖延/遗漏）
- 孩子在家提到的学校感受（开心/困扰的事）
- 孩子自己反映的学习困难点

**Step 2：回顾老师反馈**
- 查看家校联系本/班级群的老师评语
- 回忆孩子转述的老师课堂反馈
- 整理之前家长会/沟通的记录

**Step 3：明确沟通目标**
- 你最想了解的 1-2 个核心问题是什么？
- 你希望老师提供什么具体帮助？
- 你能配合老师做哪些家庭支持？

### 二、问题清单模板

#### 学习方面
| 问题 | 优先级 | 老师反馈（会后填写） |
|------|--------|---------------------|
| 孩子课堂参与度如何？ | 高/中/低 | |
| 哪些知识点掌握薄弱？ | 高/中/低 | |
| 作业质量与课堂表现是否一致？ | 高/中/低 | |
| 适合推荐什么拓展学习资源？ | 高/中/低 | |

#### 行为与社交方面
| 问题 | 优先级 | 老师反馈（会后填写） |
|------|--------|---------------------|
| 孩子与同学相处如何？ | 高/中/低 | |
| 课堂纪律/专注力如何？ | 高/中/低 | |
| 孩子有什么突出优点/特长？ | 高/中/低 | |

#### 家校配合
| 问题 | 优先级 | 老师反馈（会后填写） |
|------|--------|---------------------|
| 家庭辅导重点应放在哪里？ | 高/中/低 | |
| 需要报课外辅导班吗？ | 高/中/低 | |
| 老师推荐的复习/预习方法？ | 高/中/低 | |

### 三、会后跟进计划

1. **当天**：整理笔记，记录老师关键建议
2. **3 天内**：与孩子分享家长会内容（正面为主）
3. **1 周内**：制定 1-2 个具体改进行动
4. **2 周后**：检查改进效果，必要时再次沟通

### 四、注意事项

- **不要**在家长会上比较孩子与其他同学
- **不要**当着其他家长的面讨论孩子的具体问题
- **要**用"我观察到..."而非"你为什么..."的沟通方式
- **要**感谢老师的付出，建立积极的家校关系
- **要**关注孩子的情绪健康，不仅是分数
