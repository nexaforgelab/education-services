# Learning Environment Setup Skill

## 用途

把"家庭学习环境"从"孩子在自己房间做作业"提升为"物理 + 心理 + 时间"三方位系统。

## 触发场景

- 新学期开始
- 孩子学习状态差
- 家长问"怎么布置书桌"
- 孩子注意力不集中

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| grade | ✅ | 年级 |
| current_problems | ❌ | 家长观察到的具体问题 |
| space | ❌ | 现有家庭空间 |
| budget | ❌ | 预算 |

## 输出

### `learning_environment.md`

```markdown
# 家庭学习环境改造方案

> 学生：xxx | 年级：七年级
> 现状：孩子在自己房间写作业，但经常被手机/电视干扰

## 一、物理环境

### 书桌布置
- **位置**：远离床、远离电视
  - 床在东，书桌在西
  - 不在卧室（建议在客厅一角或专门学习室）
- **尺寸**：长 1.2 m 以上
- **桌面**：只放当前任务
  - ✓ 笔 / 教材 / 草稿纸 / 计时器
  - ✗ 手机 / 玩具 / 零食 / 与学习无关的物品

### 光线
- **自然光**：书桌左侧或正前方（右手写字的，左侧）
- **台灯**：色温 4000K 左右
  - 晚上必须开（不要只开顶灯）
  - 避免阴影（手不挡光）

### 椅子
- 高度：双脚平放地面、膝盖 90 度
- 靠背：支撑腰部

### 收纳
- 笔筒 / 文件夹 / 书包挂钩
- 每周整理一次

### 干扰源管理
- 📵 **手机**：放客厅，不在书桌
- 📺 **电视**：写作业时关闭
- 🎵 **音乐**：白噪音可以，大声不行
- 👨‍👩‍👧 **家庭活动**：作业期间不在书桌旁聊天

## 二、心理环境

### 关系基调
- **支持者** vs 监督者
  - 孩子感受到的应该是"我们一起"
  - 不是"我在盯着你"
- **不替孩子做**：让孩子自己负责

### 期待管理
- ❌ "你必须考 90 分"
- ✓ "你努力就好，考完我们一起分析"
- ❌ "你看人家小明"
- ✓ "你比上周的自己进步了"

### 错误应对
- 孩子犯错了：先共情 → 再讨论 → 最后反思
- 孩子卡住了：先鼓励 → 再提示 → 不替做

### 表扬文化
- 表扬具体行为（"你今天主动做完了数学"）
- 不表扬"聪明"（让孩子觉得能力是固定的）
- 表扬努力（"你虽然错了但没放弃"）

## 三、时间环境

### 固定学习时间

| 时段 | 时长 | 任务 |
|---|---|---|
| 放学回家 30 min | 30 min | 休息 + 吃点东西 |
| 写作业 | 60-90 min | 主任务 |
| 休息 | 10 min | 起来动一动 |
| 复习 / 预习 | 20-30 min | 明天内容 |
| 阅读 | 20-30 min | 课外书 |

### 时间块
- 番茄工作法：25 min 学习 + 5 min 休息
- 适合：注意力易分散的孩子
- 工具：手机计时器（**学习时手机放客厅**）

### 睡前仪式
- 21:00 前结束作业
- 21:00-21:30 洗漱
- 21:30 上床读书（不玩手机）
- 22:00 睡觉

## 四、第一周改造清单

- [ ] 移动书桌到合适位置
- [ ] 配齐台灯
- [ ] 清空书桌杂物
- [ ] 手机充电站移到客厅
- [ ] 买 1 个计时器
- [ ] 准备收纳盒

## 五、第 1 周适应

- 每天 21:00 与孩子"5 分钟复盘"
  - 今天做完什么？
  - 哪部分最难？
  - 明天想做什么？

## 六、避坑指南

### 常见错误

❌ 把孩子的房间当"第二战场"
   - 写作业时反复进入
   - 打断孩子思路
   - 制造紧张

❌ 用物质奖励激励
   - "做完作业给你 10 块"
   - 短期有效，长期破坏内在动机

❌ 写完作业就放松
   - 还需要复习
   - 还需要预习
   - 否则第二天跟不上

❌ 假期作息全乱
   - 假期作业堆积
   - 开学后生物钟乱

❌ 父母在旁做榜样
   - 父母玩手机，孩子也想玩
   - 父母读书，孩子也会读

## 七、长期视角

- **物理环境**：随年级调整（初高中书更多）
- **心理环境**：随孩子成长而放松（孩子越大，越需要自主空间）
- **时间环境**：随学校要求调整

## 八、家长不焦虑的方法

- **降低期待**：不是每个孩子都能考 90+
- **关注过程**：过程对，结果自然好
- **接受平庸**：接受孩子是普通孩子
- **看见进步**：纵向比，不要横向比
- **相信老师**：老师比家长更专业
```

## 环境改造优先级

### 紧急（今天就做）

1. 移走手机
2. 关闭电视
3. 清空桌面

### 重要（本周做）

1. 调整光线
2. 配计时器
3. 建立固定时间

### 长期（本月做）

1. 整理收纳
2. 建立仪式
3. 培养习惯

## 质量标准

- 具体可操作
- 优先级明确
- 不超预算
- 适合家庭实际

## 护栏

1. **不超预算**：避免高端设备强迫
2. **不强求**：有些孩子在自己房间更专注
3. **不比较**：不要"看看人家小红"
4. **不变动太大**：每周 1 个小变化更有效
5. **不忽视孩子意见**：孩子应参与布置

## 不要做的事

- 不要把"学习环境"等同于"豪华书房"
- 不要把"无手机"做成家庭矛盾
- 不要因为环境改造引发孩子抵触
- 不要把所有责任推给环境（孩子自身也重要）
