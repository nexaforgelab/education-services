# Parent Friendly Explanation Skill

## 用途

把"教研员语言"翻译成"家长能讲给孩子听的话"。

## 翻译原则

| 教研语言 | 家长语言 |
|---|---|
| 抽象概念 | 生活类比 |
| 形式化定义 | 直观描述 |
| 术语 | 大白话 |
| 长段落 | 短句 + 比喻 |
| 学术语气 | 聊天语气 |

## 翻译示例

### 例 1：负数

**教材原文**：
> 像 -3、-1.5、-7/2 这样的数叫负数。负数小于 0。

**教研员语言**：
> 负数是小于零的数，在数轴上位于零的左侧。

**家长语言**：
> 想象你借了同学 3 块钱，你没钱的程度是 "3"，用 -3 表示。
> 负数就是表示"反过来"、"欠"、"少"的数。
> 
> 比如：
> - 收入 100 元 = +100
> - 借出 50 元 = -50
> - 海平面以上 100 米 = +100
> - 海平面以下 50 米 = -50

### 例 2：异号相加

**教材原文**：
> 异号两数相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值。

**家长语言**：
> 一正一负相加，看谁"声音大"听谁的。
> -3 和 5：5 比 3 大，听 5 的，结果是正数；5-3=2，所以答案是 2
> -7 和 3：7 比 3 大，听 7 的（带负号）；7-3=4，所以答案是 -4

## 输出结构

```markdown
## 概念名：xxx

### 一句话解释
（10 字以内）

### 生活中的例子
- 例 1
- 例 2

### 怎么给孩子讲
（家长能直接照念的脚本）

### 怎么判断孩子懂没懂
- 行为 1
- 行为 2

### 不要怎么说
- 错误说法 1
- 错误说法 2
```

## 质量标准

- 家长（不限学历）能直接读懂
- 例子必须生活化、可类比
- 不写空话
- 不写"家长应该重视"这种没动作的话
