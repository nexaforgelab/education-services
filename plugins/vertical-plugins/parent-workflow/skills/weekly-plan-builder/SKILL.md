# Weekly Plan Builder Skill

## 用途

给家长一份 **可执行的、灵活的** 周计划——不堆题、不焦虑、有弹性。

## 计划原则

| 原则 | 描述 |
|---|---|
| 每天 10-30 分钟 | 不超 1 小时，留出休息 |
| 难度递进 | 周一易 → 周日难 |
| 任务具体 | 不写"复习数学"，写"做 3 道异号相加" |
| 留缓冲 | 周末留 1 天做机动 |
| 配合学校 | 跟随学校教学进度，不抢跑 |

## 输出

```markdown
# 下周学习计划（6月8日-6月14日）

> 学生：xxx
> 当前章节：有理数加减法
> 学校进度：6/10 上到"有理数加减法"
> 家庭目标：本周吃透异号相加，下周进入减法

## 周一（6/8）— 20 min
- [ ] 复习：异号相加规则
- [ ] 练习：3 道基础题
- [ ] 朗读口诀

## 周二（6/9）— 15 min
- [ ] 复习昨天的错题
- [ ] 练习：3 道变式题
- [ ] 笔记整理

## 周三（6/10）— 25 min
- [ ] 学校新内容：减法
- [ ] 看教材 p.20-p.22
- [ ] 家长讲解 + 5 道小练习

## 周四（6/11）— 20 min
- [ ] 减法化加法专项
- [ ] 5 道综合题

## 周五（6/12）— 15 min
- [ ] 单元小测前复习
- [ ] 重做错题

## 周末（6/13-14）— 30 min × 1 次
- [ ] 选 1 天做：综合应用题 3 道
- [ ] 选 1 天休息或自由复习

## 弹性空间
- 任何一天孩子不想学，可换到另一天
- 任务量减半也是可以的
- 周末可做机动

## 配套
- 教材：人教版数学七年级上册
- 配套练习：教材 p.23 习题 1.3
- 推荐工具：草稿纸、铅笔、计时器
```

## 任务类型

| 类型 | 时长 | 频率 |
|---|---|---|
| 朗读口诀 | 2 min | 每天 |
| 看教材 | 5 min | 每天 |
| 基础练习 | 5-10 min | 每天 |
| 错题回顾 | 5-10 min | 隔天 |
| 综合应用 | 15-20 min | 周末 |
| 单元小测 | 30 min | 单元末 |

## 质量标准

- 每天任务具体到题目
- 不堆题
- 有弹性
- 不超过 30 min/天
- 配合学校进度
