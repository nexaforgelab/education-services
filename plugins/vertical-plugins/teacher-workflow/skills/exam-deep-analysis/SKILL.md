# Exam Deep Analysis Skill

## 用途

把"考完试"从"看分数"提升为"按维度、按知识点、按学生"的全方位诊断与改进方案。

## 触发场景

- 期中 / 期末考试后
- 模考分析
- 单元测试后
- 班级整体学情诊断

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| exam_id | ✅ | 考试 ID |
| scores | ✅ | 学生分数列表 |
| items | ✅ | 题目列表（含每题分值、考点、难度） |
| student_answers | ❌ | 学生作答（用于错因分析） |
| curriculum_map | ❌ | 教材知识图谱 |

## 评价指标详解

### 难度系数 P

```
P = 题目平均分 / 题目满分
```

| P 范围 | 评价 |
|---|---|
| P > 0.85 | 偏易，建议增加难度 |
| 0.7 < P < 0.85 | 合适（基础题） |
| 0.5 < P < 0.7 | 合适（中等题） |
| 0.3 < P < 0.5 | 较难（拔高题） |
| P < 0.3 | 偏难，建议降低 |

### 区分度 D

```
D = (高分组得分率 - 低分组得分率)
```

| D 范围 | 评价 |
|---|---|
| D > 0.4 | 优秀 |
| 0.3 < D < 0.4 | 良好 |
| 0.2 < D < 0.3 | 一般 |
| D < 0.2 | 差，建议修改 |

## 工作流

```
输入 (scores, items, answers)
  ↓
1. 整体数据
   - 平均分 / 中位数 / 标准差 / 极值
  ↓
2. 分数段分布
  ↓
3. 题目难度 + 区分度
   - 每题计算 P、D
  ↓
4. 知识点掌握度
   - 关联到 curriculum_map
  ↓
5. 错因归类
  ↓
6. 学生分层
  ↓
7. 教学建议
   - 短期 / 中期 / 长期
  ↓
8. 家长沟通
  ↓
9. 出题反思
```

## 质量标准

- 数据准确
- 难度 / 区分度计算无误
- 错因归类合理
- 建议可执行

## 护栏

1. **不公开排名**：不写具体学生排名
2. **不羞辱学生**：不写"差生"等
3. **不下绝对判断**：避免"必然"、"一定"
4. **可执行**：建议必须能落地
5. **数据驱动**：基于真实数据

## 不要做的事

- 不要把"考试失败"全归因于学生
- 不要写"我们班太差了"
- 不要在报告中提及具体学生姓名
- 不要把"难度系数"作为唯一标准
- 不要忽视"非知识"因素（心态、时间）
