# Differentiated Instruction Skill

## 用途

为同一节课设计 **3 个层次** 的任务，覆盖全班学生。

## 三层任务

| 层次 | 对象 | 任务特征 | 完成时间 | 评价标准 |
|---|---|---|---|---|
| 基础 | 基础薄弱 | 模仿、步骤化、单点 | 5-8 min | 全对 |
| 中等 | 中等 | 应用、变式、2-3 步 | 8-12 min | 80% 正确 |
| 拔高 | 拔高 | 探究、综合、推广 | 12-15 min | 有独特思路 |

## 输出

```markdown
## 分层任务：有理数加减法

### 基础层（A 组）
- 1. 计算 (-3) + 5 = ?
- 2. 计算 (-3) - (-5) = ?
- 3. 计算 7 - (-3) = ?

**完成时间**：5 min
**评价标准**：3 题全对

### 中等层（B 组）
- 1. 计算 |3-5| + (-2) - 1
- 2. 计算 (-3) + 5 - 2 + (-1)
- 3. 温度从 -5°C 上升 7°C，是多少？

**完成时间**：8 min
**评价标准**：80% 正确

### 拔高层（C 组）
- 1. 探究：a + (-a) = ? 任意 a 成立吗？为什么？
- 2. 推广：异号两数相加 |a| < |b| 时，结果有什么规律？
- 3. 应用：编一道用减法的应用题并解答

**完成时间**：12 min
**评价标准**：有独特思路

## 分组建议
- A 组：基础薄弱 + 新转学
- B 组：班级大多数
- C 组：学有余力
- 跨组调整：根据近期表现每 2 周调整一次

## 跨层次互动
- C 组可当"小老师"辅导 A 组
- B 组挑战 C 组（自愿）
- 避免标签化，不公开分组名单
```

## 质量标准

- 三层都有
- 任务具体可执行
- 评价标准清晰
- 时间标注准确
- 不公开分组（避免标签化）
