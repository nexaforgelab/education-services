# Blackboard Design Skill

## 用途

把教学内容"可视化到黑板"——树状结构、表格、流程图，标注页码便于学生课后翻书。

## 板书类型

| 类型 | 适用 | 示例 |
|---|---|---|
| 树状 | 概念体系 | 主标题 → 概念 1/2/3 → 例题 |
| 表格 | 对比、分类 | 同号/异号 加法规则对比 |
| 流程 | 步骤化 | 解方程流程图 |
| 图示 | 几何、空间 | 数轴、几何图 |
| 列表 | 关键点 | 注意事项 5 条 |

【颜色】
- 主标题：白色粉笔
- 概念：黄色
- 例题：蓝色
- 重要规则：红色框出

【布局】
- 主标题占顶部 1/5
- 主体三栏并列
- 临时演算区在右下角
```

## 质量标准

- 布局清晰可读
- 关键点用颜色/框标注
- 页码引用完整
- 留有临时演算空间
- 学生课后能"看着黑板回忆"
