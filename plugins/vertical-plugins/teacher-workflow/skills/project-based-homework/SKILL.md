# Project Based Homework Skill

## 用途

设计"长周期、跨学科、真实情境、过程性评价"的项目式作业——区别于传统刷题作业。

## 触发场景

- 单元 / 学期大作业
- 寒暑假作业
- 跨学科主题活动
- 综合实践活动

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| topic | ✅ | 主题（如"调查家庭用电"） |
| grade | ✅ | 年级 |
| duration_days | ✅ | 时长（天/周） |
| subject_integration | ❌ | 跨学科（如"数学+科学+语文"） |
| class_size | ❌ | 班级人数 |
| deliverables | ❌ | 期望交付物 |

## 输出

### `project_assignment.md`

```markdown
# 项目式作业：调查家庭一周用电

> 主题：家庭能源调查 | 学科：数学+科学+语文
> 年级：六年级 | 时长：2 周
> 提交：调查报告 + 数据图表 + 节能建议书

## 一、项目目标

### 知识
- 数学：统计图表、平均数、百分比
- 科学：电能单位、用电安全
- 语文：调查报告写作、数据说明

### 能力
- 数据收集与处理
- 跨学科综合
- 团队协作（可选）
- 真实问题解决

### 素养
- 节能意识
- 科学态度
- 沟通表达

## 二、驱动问题

> "我们家的电是怎么用的？哪些地方可以更节能？"

## 三、项目阶段

### 第 1 阶段：准备（2 天）
- 任务：
  1. 全家讨论，决定"重点观察" 1-2 个用电器
  2. 设计"用电记录表"
  3. 准备计时工具
- 产出：记录表设计

### 第 2 阶段：数据收集（7 天）
- 任务：
  1. 每天记录重点电器的使用时间和功率
  2. 拍摄 3 张"家庭用电场景"照片
  3. 与家人讨论"用电是否合理"
- 产出：原始数据

### 第 3 阶段：数据分析（3 天）
- 任务：
  1. 计算总用电量
  2. 制作统计图（柱状图 / 饼图）
  3. 计算人均 / 日均 / 月均
- 产出：图表 + 简短说明

### 第 4 阶段：报告与建议（3 天）
- 任务：
  1. 写 800 字"家庭用电调查报告"
  2. 列出 3-5 条"节能建议"
  3. 制作"节能小贴士"卡片（可分享给家人）
- 产出：调查报告 + 节能卡片

## 四、过程性评价

| 阶段 | 评价点 | 自评 | 家长评 | 老师评 |
|---|---|---|---|---|
| 1 | 记录表设计 |  |  |  |
| 2 | 数据完整性 |  |  |  |
| 3 | 图表质量 |  |  |  |
| 4 | 报告深度 |  |  |  |

## 五、最终评价标准

| 维度 | 占比 | 评分要点 |
|---|---|---|
| 数据真实 | 30% | 完整记录 7 天 |
| 数据处理 | 25% | 图表清晰、计算正确 |
| 报告写作 | 25% | 结构合理、说明清晰 |
| 建议可行 | 15% | 至少 3 条具体建议 |
| 创意 / 美观 | 5% | 排版、附加元素 |

## 六、家长指导

### 家长可做
- 协助查电费单 / 电器铭牌
- 监督孩子完成记录
- 一起讨论节能建议

### 家长不要做
- 替孩子完成数据
- 替孩子写报告
- 替孩子做图表

## 七、可能问题与应对

| 问题 | 应对 |
|---|---|
| 孩子不感兴趣 | 从"自家冰箱"等小主题切入 |
| 数据不真实 | 中间检查 1-2 次 |
| 家长干预过多 | 强调"过程比结果重要" |
| 工具不足 | 鼓励用手机 Excel / 纸笔 |

## 八、跨学科关联

| 学科 | 关联点 |
|---|---|
| 数学 | 统计、百分比、单位换算 |
| 科学 | 电能、功率、用电安全 |
| 语文 | 调查报告写作 |
| 信息技术 | Excel / PPT |
| 道法 | 节能、可持续发展 |
```

## 项目式作业特点

### 与传统作业对比

| 维度 | 传统作业 | 项目式作业 |
|---|---|---|
| 时长 | 30-60 min | 1-4 周 |
| 学科 | 单科 | 跨学科 |
| 评价 | 结果 | 过程 + 结果 |
| 答案 | 唯一 | 多元 |
| 能力 | 知识 | 知识 + 能力 + 素养 |

### 设计原则

| 原则 | 说明 |
|---|---|
| 真实情境 | 来自生活 / 真实问题 |
| 驱动问题 | 激发兴趣、贯穿全程 |
| 学生中心 | 学生主导、教师引导 |
| 过程评价 | 关注过程而非只关注结果 |
| 公开展示 | 让学生有"成就感" |

## 常见项目主题

### 数学 / 科学

- 家庭用电 / 用水调查
- 校园植物调查
- 家庭月度收支规划
- 旅行方案设计（预算 / 路线）
- 校园浪费调查

### 语文 / 历史

- 家族口述史
- 家乡变化调查
- 校园文学报
- 一本书的"研究"

### 跨学科

- "如果我是校长"——校园设计提案
- "未来城市"——科幻创意 + 物理 + 美术
- "传统文化"——调研 + 视频 + 海报

## 工作流

```
输入 (topic, grade, duration, subjects)
  ↓
1. 定主题
   - 真实情境 + 跨学科
  ↓
2. 驱动问题
   - 1 个核心问题
  ↓
3. 拆阶段
   - 准备 / 收集 / 处理 / 报告
  ↓
4. 评价设计
   - 过程性 + 结果性
  ↓
5. 家长指导
   - 配合 + 边界
  ↓
6. 应急预案
   - 工具不足 / 兴趣不足
```

## 质量标准

- 主题真实可操作
- 驱动问题清晰
- 阶段任务具体
- 评价标准可量化
- 家长指导明确

## 护栏

1. **不超纲**：学科知识不超过年级
2. **可执行**：所有任务能完成
3. **可负担**：不占用太多家庭时间
4. **可评价**：评价标准清晰
5. **不超预算**：不强制购买器材
6. **不替代家长**：明确家长边界

## 不要做的事

- 不要设计"看起来很美但做不了"的项目
- 不要把"研究"变成"AI 代做"
- 不要让项目变成"家长作业"
- 不要把评价标准定得太高
- 不要遗漏"过程评价"
