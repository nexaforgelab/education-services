# Classroom Management Tips Skill

## 用途

把"课堂管理"从"靠吼"提升为"靠规则、靠策略、靠关系"。

## 触发场景

- 新教师第一年
- 接手新班级
- 班级纪律问题
- 学生注意力分散
- 突发事件

## 核心原则

### 黄金三角

```
        规则
        /\
       /  \
      /    \
     /  关系 \
    /________\
   规则+策略+关系
```

| 维度 | 占比 | 含义 |
|---|---|---|
| 关系 | 50% | 与学生建立信任 |
| 规则 | 30% | 明确的规则 + 一致执行 |
| 策略 | 20% | 应对不同情境的技巧 |

## 一、建立规则

### 开学第一周关键

1. **共同制定**
   - 让学生参与规则制定
   - 班级讨论 → 投票 → 张贴
   - 学生更愿意遵守自己定的规则

2. **规则要少**
   - 5-7 条核心规则即可
   - 不要 30 条（记不住）

3. **可视化**
   - 贴教室墙上
   - 班会上定期重温

### 推荐的核心规则（5-7 条）

1. 尊重他人（不打断、不嘲笑）
2. 认真听讲（眼神交流、不随便说话）
3. 按时完成作业
4. 物品摆放整齐
5. 进出教室有礼
6. 主动提问和求助
7. 不带手机（如果学校允许）

## 二、维护关系

### 关键行为

| 行为 | 示例 |
|---|---|
| 记住学生名字 | "小明，上次你的想法很棒" |
| 关注学生情绪 | "你今天看起来不开心，需要聊聊吗？" |
| 公平一致 | 同样的规则适用所有人 |
| 表扬具体 | "你今天举手 3 次，很好" |
| 私下批评 | 不在全班面前批评个人 |

### 关系建立的 4 个关键时刻

1. **开学第一周**：印象奠基
2. **学生生病 / 出事**：表达关心
3. **学生进步时**：具体表扬
4. **学生失败时**：陪伴 + 鼓励

## 三、注意力管理

### 注意力曲线

```
注意力
   ↑
   │  ╱╲
   │ ╱  ╲        ╱╲
   │╱    ╲      ╱  ╲
   │      ╲    ╱    ╲
   │       ╲  ╱      ╲
   │        ╲╱        ╲
   └────────────────────→ 时间
   0  10  20  30  40 min
```

- 0-15 min：注意力高峰
- 15-25 min：开始走神
- 25-30 min：低谷
- 30+ min：可短暂恢复

### 应对策略

| 策略 | 适用 | 效果 |
|---|---|---|
| 切换活动 | 注意力低谷 | 重新激活 |
| 提问互动 | 全程 | 维持参与 |
| 小组讨论 | 25 min 后 | 互动激活 |
| 课堂练习 | 30 min 后 | 实践巩固 |
| 站起来活动 | 25 min 后 | 身体激活 |
| 幽默 / 故事 | 注意力分散 | 重新吸引 |

## 四、行为管理

### 渐进式干预

| 步骤 | 行为 | 措施 |
|---|---|---|
| 1 | 走神 | 眼神提醒 |
| 2 | 继续走神 | 走近 |
| 3 | 还在走神 | 点名回答问题 |
| 4 | 干扰他人 | 站到他旁边 |
| 5 | 故意捣乱 | 课后谈话 |
| 6 | 拒绝配合 | 找班主任 / 家长 |

### 避免的雷区

❌ 当众羞辱："这道题都不会，你是不是傻？"
❌ 翻旧账："你上次也是这样"
❌ 体罚 / 变相体罚
❌ 拖堂（占用学生休息）
❌ 比较（"看看人家"）

## 五、突发事件应对

### 学生冲突

```
Step 1: 立即分开
Step 2: 各自冷静（5 min）
Step 3: 听双方说法（不预判）
Step 4: 让双方各自反思
Step 5: 引导道歉 / 和解
Step 6: 后续跟进
```

### 学生突然情绪崩溃

```
Step 1: 立即带离教室（避免围观）
Step 2: 在办公室 / 走廊陪伴
Step 3: 安静陪伴（不急于问）
Step 4: 等他准备好再说
Step 5: 通知家长
Step 6: 必要时联系心理老师
```

### 上课设备故障

```
Plan A: 用白板代替 PPT
Plan B: 让学生先做练习
Plan C: 临时改讨论课
```

### 教学突发失误

```
坦诚说："老师刚才说错了，正确答案是 ..."
示范"犯错—承认—修正"的过程
```

## 六、奖励与惩罚

### 奖励原则

| ✅ 推荐 | ❌ 不推荐 |
|---|---|
| 表扬具体行为 | 表扬"聪明" |
| 公开表扬 | 公开排名 |
| 精神奖励 | 物质奖励 |
| 即时反馈 | 延后奖励 |
| 多元奖励 | 单维奖励 |

### 惩罚原则

| 原则 | 说明 |
|---|---|
| 最小化 | 最小必要惩罚 |
| 一致性 | 同样行为同样处理 |
| 及时性 | 发生后立即处理 |
| 不羞辱 | 不公开羞辱 |
| 不记仇 | 惩罚后正常对待 |
| 不伤害 | 不得造成心理/身体伤害 |

## 七、班级文化

### 营造积极氛围

1. **班级口号**：简短 + 积极
   - "每天进步一点点"
   - "我们在一起"
2. **班级公约**：所有学生参与制定
3. **班级仪式**：
   - 每日一句（名言 / 鼓励）
   - 每周一歌
   - 每月之星
4. **学习角落**：图书角 / 错题本角 / 展示角

### 班级自治

- 设立班委：班长、学习委员、纪律委员
- 值日班长：每天轮换
- 学习小组：4-6 人一组
- 互相监督 + 互相帮助

## 八、家校配合

### 早期沟通

- 每学期 1 次主动联系（不等到出问题）
- 分享学生的进步（不只是问题）
- 邀请家长参与班级活动

### 问题沟通

- 客观描述（见 parent-teacher-comm）
- 不指责、不命令
- 共同寻找方案

## 工作流

```
教师遇到管理问题
  ↓
1. 分析问题类型
   - 走神 / 冲突 / 情绪 / 设备 / 教学
  ↓
2. 选干预策略
   - 渐进式 / 私下 / 公开
  ↓
3. 立即行动
  ↓
4. 观察效果
  ↓
5. 调整策略
  ↓
6. 长期跟进
```

## 质量标准

- 干预及时
- 不羞辱
- 关系导向
- 长期视角

## 护栏

1. **不体罚**：违反师德
2. **不羞辱**：违反教育规律
3. **不偏见**：公平一致
4. **不越界**：心理/医疗问题转介

## 不要做的事

- 不要靠"凶"建立威信
- 不要把所有问题归因于学生
- 不要在全班面前点名批评
- 不要比较学生
- 不要在情绪激动时处理问题
