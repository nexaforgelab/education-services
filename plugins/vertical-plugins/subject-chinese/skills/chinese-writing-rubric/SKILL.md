# Chinese Writing Rubric Skill

## 用途

把语文作文批改从"凭感觉打分"提升为"按维度、按权重、按档次"的可重复评分。

## 评分维度（6 维）

| 维度 | 占比 | 评分要点 |
|---|---|---|
| 内容 (Content) | 25% | 切题、中心、素材、深度 |
| 结构 (Structure) | 15% | 段落、过渡、详略、首尾 |
| 语言 (Language) | 20% | 通顺、准确、无语病 |
| 文采 (Literary) | 15% | 修辞、句式、词汇丰富 |
| 书写 (Handwriting) | 15% | 规范、整洁、美观 |
| 创新 (Creativity) | 10% | 立意新、角度新、表达新 |

## 学段适配

| 学段 | 常见文体 | 字数要求 |
|---|---|---|
| 小学低年级 | 看图写话、造句 | 50-150 |
| 小学高年级 | 记叙文、简单应用文 | 300-500 |
| 初中 | 记叙文、说明文、议论文、应用文 | 500-700 |
| 高中 | 议论文为主、记叙文、应用文 | 800-1000 |

## 触发场景

- 教师批改作文
- 学生需要评分
- 写作模板生成
- 单元复习

## 二、档次（中考标准）

| 档次 | 分值 | 本卷 |
|---|---|---|
| 一档（优秀） | 50-60 | |
| 二档（良好） | 40-49 | ✓ |
| 三档（及格） | 30-39 | |
| 四档（不及格） | < 30 | |

> 注：中考作文满分 60 分，转换为 100 分制。

## 三、亮点
1. 题目"那一刻"具体化，避免空泛
2. 选材真实（学骑车）
3. 心理描写细腻
4. 结尾呼应题目

## 四、改进点
1. **第 3 段** "我" 的心理可再细化（300 字 → 400 字）
2. **第 4 段** 父亲的话可以更生活化
3. 词汇重复："紧张"出现 3 次
4. 立意：从"学会骑车"到"理解父爱"的升华可更明确

## 五、推荐提升模板

### 开头（"那一刻"具体化）
> 标准：时间 + 地点 + 场景 + 情绪
> 模板："那是一个 ____（时间）的 ____（地点），我 ____（场景），心中 ____（情绪）。"

### 主体（细节描写）
> 视觉：看到 ____
> 听觉：听到 ____
> 触觉：感到 ____
> 心理：想到 ____

### 结尾（升华主题）
> 模板："那一刻，我 ____（动作），却 ____（感悟）——我 ____（成长）。"

## 评分流程

```
输入作文
  ↓
1. 基本检查
   - 字数是否符合（±10%）
   - 是否扣题
   - 是否完整
  ↓
2. 6 维评分
   - 内容 25 + 结构 15 + 语言 20 + 文采 15 + 书写 15 + 创新 10
  ↓
3. 总分 + 档次
  ↓
4. 反馈
   - 亮点
   - 改进点
   - 提升模板
```

## 质量标准

- 6 维评分一致率 ≥ 85%（与教师手改）
- 字数判定准确
- 反馈具体到段落
- 模板可复用

## 护栏

1. **不羞辱学生**：不写"基础太差"
2. **基于文本**：评语必须基于实际作文
3. **不空泛**：不写"再努力一点"
4. **不歧视**：评价不涉及学生背景
5. **可执行改进**：每条改进点都能落地
6. **文化敏感**：不评判学生文化背景
7. **不代写**：不替学生改写全文

## 不要做的事

- 不要把所有错误都列出
- 不要写"语法错误太多"这种没价值的评语
- 不要替学生改写全文
- 不要在批注中用"!"等情绪化符号
- 不要因为"漂亮"就给高分
- 不要给"范文"式评语（不切实际）
