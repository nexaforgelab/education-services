# Chinese Poetry Appreciation Skill

## 用途

把"古诗词鉴赏"从"死记译文"提升为"五步鉴赏法"的可训练能力。

## 五步鉴赏法

```
Step 1: 读懂字面
   ↓
Step 2: 找意象
   ↓
Step 3: 品意境
   ↓
Step 4: 悟情感
   ↓
Step 5: 赏技巧
```

## 触发场景

- 古诗新授课
- 鉴赏题失分
- 中高考复习
- 家长辅导

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| poem | ✅ | 古诗全文 |
| author | ❌ | 作者 |
| era | ❌ | 朝代 |
| textbook_id | ✅ | 教材 ID |
| chapter_id | ✅ | 章节 |
| grade | ✅ | 年级 |

## 输出

### `poem_appreciation.md`

```markdown
# 《登幽州台歌》鉴赏（教材 p.78）

> 作者：陈子昂 | 朝代：唐 | 体裁：古体诗
> 全诗：前不见古人，后不见来者。念天地之悠悠，独怆然而涕下。

## Step 1：读懂字面

- 古人：古代那些能礼贤下士的圣君
- 来者：后世重视人才的明君
- 悠悠：长久、广阔
- 怆然：悲伤的样子
- 涕：眼泪

**翻译**：
向前看不见古代的圣君，向后看不到后世的明君。想到天地之间无穷无尽，唯独我感到悲伤而流下眼泪。

## Step 2：找意象

| 意象 | 含义 |
|---|---|
| 古人 | 礼贤下士的圣君（理想） |
| 来者 | 重才的明君（理想） |
| 天地 | 广阔无边、永恒 |
| 涕 | 悲伤之极 |

**没有具体景物**——纯议论 + 抒情

## Step 3：品意境

- **空间上**：前后不见 → 孤独
- **时间上**：天地悠悠 → 永恒对比个人短暂
- **情感上**：怆然涕下 → 悲从中来

**意境特点**：宏大、苍凉、孤独

## Step 4：悟情感

| 层次 | 情感 |
|---|---|
| 表面 | 怀才不遇 |
| 深层 | 理想幻灭 |
| 哲学 | 个人在时空中的渺小 |

## Step 5：赏技巧

### 1. 对比
- 古人 vs 来者（纵向时间对比）
- 天地悠悠 vs 个人（横向空间对比）

### 2. 直抒胸臆
- "念天地之悠悠，独怆然而涕下"
- 不借景抒情，直接说感受

### 3. 短句
- 全诗 6 句，短促有力
- 体现"怆然"的急促情绪

### 4. 用典
- "前不见古人" 用燕昭王筑台招贤典故

## 配套练习

### 1. 基础题
- 解释"悠悠"和"怆然"
- 翻译"念天地之悠悠，独怆然而涕下"

### 2. 意境题
- 全诗营造了怎样的意境？
- "前后"两个字的对比作用是什么？

### 3. 情感题
- 诗人"涕下"的原因是什么？
- 全诗表达了诗人怎样的情感？

### 4. 技巧题
- 全诗主要运用了什么表现手法？
- "独"字在表情达意上的作用？
```

## 表现手法速查

| 手法 | 作用 | 识别标志 |
|---|---|---|
| 借景抒情 | 情景交融 | 景语 + 情语 |
| 托物言志 | 借物喻人 | 物 + 品格对应 |
| 用典 | 丰富内涵 | 历史人物/故事 |
| 比喻 / 拟人 | 形象生动 | 喻体/拟体 |
| 夸张 | 突出特征 | 数字、程度 |
| 对比 | 突出情感 | 前后 / 上下对比 |
| 动静结合 | 灵动画面 | 静景 + 动景 |
| 虚实结合 | 意境深远 | 实景 + 虚景 |
| 直抒胸臆 | 强烈情感 | "我..." "吾..." |
| 借古讽今 | 含蓄表达 | 古事 + 当下 |

## 答题模板

### 意境题
> 这首诗营造了 ____（特点）的意境，
> 通过 ____（意象），
> 表达了诗人 ____（情感）。

### 情感题
> 全诗表达了诗人 ____ 的情感，
> 其中 ____（诗句）最能体现，
> 原因是 ____。

### 技巧题
> 这首诗运用了 ____ 手法，
> 通过 ____（具体内容），
> 起到了 ____（效果）的作用。

## 工作流

```
输入古诗
  ↓
1. Step 1 字面
   - 关键难字注解
   - 翻译
  ↓
2. Step 2 意象
   - 列出所有意象
   - 标含义
  ↓
3. Step 3 意境
   - 整体氛围
   - 空间 / 时间维度
  ↓
4. Step 4 情感
   - 表面 / 深层 / 哲学
  ↓
5. Step 5 技巧
   - 表现手法
   - 修辞手法
  ↓
6. 配套练习
```

## 质量标准

- 翻译准确
- 意象识别完整
- 意境概括有诗意
- 情感分析有层次
- 技巧标手法名称

## 护栏

1. **不曲解诗意**：不强行赋予现代价值观
2. **不过度阐释**：避免"过度解读"
3. **不脱离背景**：必须结合时代背景
4. **不堆典故**：关联的典故要服务于理解
5. **不歧视**：避免对古人/朝代的主观评判
6. **不直接给答案**：用提问引导思考

## 不要做的事

- 不要把古诗讲成"政治符号"
- 不要把诗人讲成"完美人格"
- 不要用"现代白话文"思维解古诗
- 不要在分析中加入"封建糟粕"等标签
- 不要给"标准答案"（用答题模板）
