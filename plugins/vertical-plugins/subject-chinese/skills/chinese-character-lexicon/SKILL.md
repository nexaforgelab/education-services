# Chinese Character Lexicon Skill

## 用途

把"教材生字表"提升为"可记忆、可运用、可辨析"的字词学习包。

## 处理维度（6 维）

| 维度 | 内容 |
|---|---|
| 字形 | 笔画、笔顺、结构、偏旁 |
| 字音 | 读音（多音字）、声调 |
| 字义 | 本义、引申义、语境义 |
| 组词 | 常见组词 3-5 个 |
| 造句 | 教材原句 + 1-2 个新例句 |
| 辨析 | 形近字、同音字、近义词 |

## 触发场景

- 新单元开始
- 字词听写复习
- 错字纠正

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| char_list | ✅ | 生字列表 |
| grade | ✅ | 年级 |
| textbook_id | ✅ | 教材 ID |
| chapter_id | ✅ | 章节 |
| focus | ❌ | 字形/字音/字义/辨析 |

## 输出

### `character_deck.md`

```markdown
# 七年级上册 第 3 课 生字（教材 p.32-35）

## 1. 骤 (zhòu)

### 字形
- 笔画：19 画
- 结构：左右结构（马 + 聚）
- 偏旁：马字旁
- 易错点：右上是"聚"，不是"聚"少一点

### 字音
- 读音：zhòu（第四声）
- 多音字：无
- 易错读音：注意声母是 zh 不是 z

### 字义
- 本义：马跑得快
- 引申义：迅速、突然
- 常用义：突然（骤然、急骤）

### 组词
- 骤然 / 急骤 / 骤雨 / 步骤
- 暴风骤雨 / 急骤变化

### 教材原句
- 天气**骤**变，要下雨了。（教材 p.33）
- 听到这个**骤**然的消息，他惊呆了。（教材 p.34）

### 造句
- 一阵骤雨过后，天空放晴了。

### 辨析

#### 形近字：聚
- 骤：马字旁，与"快"有关
- 聚：人字头，与"人"有关
- 区分：骤有"马"，聚有"人"

#### 易错字：注意右上是"聚"
- 错字：骤 写成 "驟"（异体字）
- 错字：骤 写成 "驟" 少一点

### 听写要点
- 听到"zhòu"时想"马字旁 + 聚"
- 写完检查：右上是"聚"不是"取"（容易写错）

## 2. 匿 (nì)

### 字形
- 笔画：10 画
- 结构：半包围
- 偏旁：卩
- 易错点：右上"若"少一点

### 字音
- 读音：nì（第四声）
- 易错：声母是 n，不是 l

### 字义
- 本义：隐藏
- 常用义：藏匿、隐匿

### 组词
- 藏匿 / 隐匿 / 销声匿迹 / 匿名

### 教材原句
- 他**匿**名举报了这件事。（教材 p.36）
- 罪犯**匿**藏在深山中。（教材 p.37）

### 辨析

#### 形近字：若
- 匿：若 + 卩（半包围）
- 若：艹 + 右（上下）

#### 同音字：腻、溺、逆
- 匿：藏匿
- 腻：油腻、腻烦
- 溺：溺水
- 逆：逆流、逆境

### 听写要点
- 听到"nì"时想"若 + 卩"
- 易错：写成"若"（漏卩）
```

## 核心考点

### 字形类

| 考点 | 训练方式 |
|---|---|
| 笔画 | 数笔画、按笔顺写 |
| 偏旁部首 | 识别偏旁、理解含义 |
| 易错字 | 标红错例、对比辨析 |
| 形近字 | 列表对比、口诀记忆 |

### 字音类

| 考点 | 训练方式 |
|---|---|
| 多音字 | 整理多音字表 |
| 易错读音 | 标注重难点 |
| 形声字读音 | 同声旁不一定同音 |

### 字义类

| 考点 | 训练方式 |
|---|---|
| 一字多义 | 整理义项 |
| 古今异义 | 关联古文 |
| 语境义 | 选词填空 |

### 辨析类

| 考点 | 训练方式 |
|---|---|
| 形近字 | 列表对比 |
| 同音字 | 关联语境 |
| 近义词 | 找细微差异 |

## 工作流

```
输入生字表
  ↓
1. 教材核查
   - 每个字找 1-2 个教材原句（带 page_ref）
  ↓
2. 字形分析
   - 笔画 / 笔顺 / 结构 / 偏旁
   - 易错点
  ↓
3. 字音
   - 读音 / 多音字 / 易错读
  ↓
4. 字义
   - 本义 / 引申义 / 语境义
  ↓
5. 组词 + 造句
  ↓
6. 辨析
   - 形近 / 同音 / 近义
  ↓
7. 听写要点
```

def build_character_deck(char_list, grade, textbook_id, chapter_id):

        entry = {

## 质量标准

- 字形 / 读音 100% 准确
- 教材原句 100% 引用页码
- 辨析基于权威工具书
- 听写要点可操作

## 护栏

1. **不编造字形**：基于权威字典
2. **不堆字义**：每字选 3-5 个核心义
3. **不脱离语境**：例句必须真实
4. **不歧视**：避免涉及不雅字词

## 不要做的事

- 不要把"罕见义"列出
- 不要把"形近字"列 5+ 个（2-3 个就够）
- 不要给"谐音字"凑数（如"鸡"吉，不是字义相关）
- 不要把"汉字故事"作为字义依据
