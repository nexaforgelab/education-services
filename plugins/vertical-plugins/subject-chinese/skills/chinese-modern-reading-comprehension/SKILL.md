# Chinese Modern Reading Comprehension Skill

## 用途

把"现代文阅读"从"凭感觉答"提升为"按文体、按题型、按策略"的能力训练。

## 文体 × 题型矩阵

| 文体 | 核心考点 | 典型题型 |
|---|---|---|
| 记叙文 | 情节、人物、主题 | 内容理解、人物分析、主题概括 |
| 说明文 | 说明对象、说明方法、说明语言 | 信息提取、方法识别、作用分析 |
| 议论文 | 论点、论据、论证 | 论点概括、论据分析、论证方法 |
| 散文 | 形散神聚、语言特色、情感 | 句子理解、词语赏析、主旨探究 |
| 小说 | 三要素、主题、技巧 | 人物形象、情节作用、主题挖掘 |

## 触发场景

- 教师讲阅读题
- 学生现代文失分
- 中高考阅读复习
- 家长问"怎么练阅读"

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| passage | ✅ | 文章（教材或真题） |
| questions | ✅ | 配套题目 |
| student_answers | ❌ | 学生答案 |
| grade | ✅ | 年级 |
| genre | ❌ | 文体 |

## 二、逐题诊断

### q1（内容理解，✓ 正确）
- 题型：内容理解
- 问："父亲"为"我"做了哪几件事？
- 答案要点：① 送行 ② 爬月台买橘 ③ 嘱咐
- 关键：定位"车站"段落

### q2（句子赏析，✗ 错）
- 题型：句子赏析
- 问："他用两手攀着上面，两脚再向上缩"中"攀"用得好在哪里？
- 学生答：生动形象
- 标准答案：① 准确写出了父亲爬月台时的艰难 ② 体现父亲对儿子的深沉爱意
- 错因：未结合语境
- 改进：赏析要 **结合上下文 + 扣人物情感**

### q3（词语理解，✓ 正确）
- 题型：词语理解
- 问："蹒跚"一词的含义和作用？
- 答案：① 形容走路缓慢不稳的样子 ② 体现父亲老态和对儿子的不舍

### q4（主题探究，✓ 正确）
- 题型：主题探究
- 问：文章为何以"背影"为题？
- 答案：① "背影"是父亲形象的代表 ② 凝聚父子深情 ③ 是"我"情感触发点

## 四、错题精讲

### q2 精讲

**问题**："攀"字好在哪儿？

**错误思路**：
- 只写"生动形象"——空话

**正确思路**（分层）：
1. 表面义：爬、抓
2. 语境义：父亲年龄大、体态胖，爬月台很艰难
3. 情感义：艰难还要爬，体现对儿子的爱
4. 修辞义：用动作细节描写

**模板**：
> "攀"字准确写出了父亲爬月台时的艰难动作（表义），  
> 体现父亲年迈体胖、行动不便的客观状态（语境），  
> 突出父亲不顾艰难为儿子买橘的深沉父爱（情感），  
> 用动词细节描写代替抒情，更有感染力（修辞）。

## 五、阅读策略总结

### 散文阅读"五看法"

1. **看标题**：定主题方向
2. **看开头**：定情感基调
3. **看结尾**：定主题升华
4. **看反复**：定情感关键词
5. **看过渡**：定段落关系

### 赏析题"三层答"

1. **表层**：词句的表面含义 / 修辞 / 表达方式
2. **语境层**：结合上下文，扣段落内容
3. **主题层**：扣人物情感、文章主旨

## 工作流

```
输入 (passage, questions, answers)
  ↓
1. 文体识别
   - 记叙 / 说明 / 议论 / 散文 / 小说
  ↓
2. 题目分类
   - 内容 / 赏析 / 探究 / 写法
  ↓
3. 学生答题分析
  ↓
4. 错因归类
  ↓
5. 错题精讲
   - 错误思路 vs 正确思路
  ↓
6. 策略总结
  ↓
7. 配套练习
```

## 质量标准

- 错因诊断准确率 ≥ 80%
- 精讲具体到方法
- 配套练习难度递进
- 策略可复用

## 护栏

1. **不评判学生**：不写"阅读能力差"
2. **不空泛**：不写"再认真一点"
3. **可执行**：策略可复用于其他文章
4. **不脱离原文**：分析必须基于原文
5. **不歧视**：避免涉及敏感话题

## 不要做的事

- 不要把阅读讲成"靠语感"
- 不要给"玄学"答案模板
- 不要堆"高级范文"
- 不要在分析中加入政治标签
- 不要用"过度解读"代替"文本细读"
