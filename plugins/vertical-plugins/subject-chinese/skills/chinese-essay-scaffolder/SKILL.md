# Chinese Essay Scaffolder Skill

## 用途

给"写作困难学生"提供 **可复用、可填充、可调整** 的写作支架。

不替学生写，而是 **降低起步难度**。

## 触发场景

- 学生面对题目无话可说
- 学生段落展开困难
- 学生段落字数凑不够
- 学生不会开头 / 结尾
- 家长说"我家孩子一写作文就头疼"

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| genre | ✅ | 文体（记叙/议论/说明/应用） |
| prompt | ✅ | 题目 |
| grade | ✅ | 年级 |
| word_count_required | ✅ | 字数要求 |
| student_thoughts | ❌ | 学生想到的零散想法 |

## 输出

### `essay_scaffold.md`

```markdown
# 写作支架：《那一刻，我长大了》

> 文体：记叙文 | 年级：七年级 | 字数：500-700

## 一、题目拆解

- "那一刻"：具体化（什么时刻？什么场景？）
- "我"：第一人称
- "长大了"：身体长大 / 心理长大？→ 心理更常见

## 二、结构模板（5 段式）

```
[开头] 那一刻的画面（150 字）
[起因] 那一刻之前发生了什么（100 字）
[经过] 那一刻的关键事件（200 字）
[结果] 那一刻之后我懂了什么（150 字）
[结尾] 呼应题目，升华主题（100 字）
```

## 三、段落支架

### 第 1 段：开头（150 字）

**目的**：引入场景 + 营造氛围

**模板**：
> 那是一个 ____（时间）的 ____（地点），我 ____（场景），心中 ____（情绪）。

**填空**：
- 时间：____
- 地点：____
- 场景：____
- 情绪：____

**示例**：
> 那是一个夏天的傍晚，我在小区的空地上学骑车，心中满是紧张。

### 第 2 段：起因（100 字）

**目的**：交代背景

**模板**：
> 原来 ____（背景），所以 ____（事件起因）。

### 第 3 段：经过（200 字）

**目的**：核心场景展开（4 要素）

**四要素**：
- 视觉：我看到 ____
- 听觉：我听到 ____
- 触觉/心理：我感到 ____
- 动作：我 ____

**模板**：
> 我 ____（动作），看到 ____（视觉），听到 ____（听觉），心中 ____（心理）。

### 第 4 段：结果（150 字）

**目的**：感悟

**模板**：
> 那一刻，我 ____（动作），却 ____（感悟）——
> 原来 ____（更深理解）。

### 第 5 段：结尾（100 字）

**目的**：呼应题目 + 升华

**模板**：
> 如今，我 ____（现状），
> 但我永远不会忘记 ____（那那一刻）。
> 那一刻，我 ____，真的长大了。

## 四、素材建议

### 适合"长大"主题的素材
- 学骑车摔跤
- 第一次做饭
- 考试失败后重新站起来
- 帮助他人
- 父母工作的一天
- 看到父母的老去

### 不建议的素材
- 过于戏剧化（亲人去世等）
- 太空泛（"我学会了很多"）

## 五、词汇升级

把普通词换成"成长感"更强的词：

| 普通 | 升级 |
|---|---|
| 摔倒 | 跌倒 / 摔倒 / 重重地摔在地上 |
| 紧张 | 心跳加速 / 紧握车把 / 屏住呼吸 |
| 害怕 | 胆战心惊 / 不敢看 / 心里发毛 |
| 终于 | 终于 / 总算 / 历经千辛万苦 |
| 长大 | 成长 / 蜕变 / 理解 / 担当 |

## 六、句式升级

把平淡句改成有"成长感"的句子：

- ❌ 我终于学会骑车了。
- ✅ 一次次摔倒，一次次爬起，那一刻，我终于学会了骑车——也学会了不放弃。

- ❌ 我懂得了什么是坚持。
- ✅ 那一刻，我懂得了：坚持不是不摔倒，而是摔倒了还能再站起来。

## 七、写作前的 5 个问题（自问）

1. 那一刻的 **时间地点** 是什么？
2. 那一刻之前 **发生了什么**？
3. 那一刻 **谁在身边**？
4. 那一刻 **我看到了 / 听到了 / 想到了什么**？
5. 那一刻之后 **我懂得了什么**？

回答完这 5 个问题，作文的"骨架"就有了。

## 八、字数凑不够的应急方法

| 方法 | 加 50 字 |
|---|---|
| 加 1 个细节 | 爸爸的手很大 / 妈妈的声音很轻 |
| 加 1 句心理 | 我心想：这次一定要成功 |
| 加 1 句景物 | 天色渐暗，路灯亮起 |
| 加 1 句对话 | "加油！别怕！" 妈妈喊道 |
| 加 1 句感受 | 我的手心全是汗 |

## 九、写完后 5 项自查

- [ ] 字数 ≥ 500？
- [ ] 有完整 5 段？
- [ ] 至少 1 个细节（视觉/听觉/触觉/心理）？
- [ ] 题目"那一刻"在开头 / 结尾出现？
- [ ] 没有"我"字过多（每段不超过 3 个"我"）？
```

## 各类文体模板

### 记叙文

```
[开头] 场景引入
[起因] 背景交代
[经过] 事件展开（细节 4 要素）
[结果] 事件结果 + 感悟
[结尾] 呼应主题
```

### 议论文

```
[开头] 引出议题 + 中心论点
[本论 1] 论点 + 论据 + 论证
[本论 2] 论点 + 论据 + 论证
[本论 3] 反面 / 深化
[结尾] 总结 + 呼吁
```

### 说明文

```
[开头] 引出说明对象
[主体 1] 特征 / 分类
[主体 2] 工作原理 / 过程
[主体 3] 用途 / 意义
[结尾] 总结特征
```

### 应用文

```
[称呼]
[正文] 事件 / 原因 / 请求
[署名 + 日期]
```

## 工作流

```
输入 (genre, prompt, grade, word_count)
  ↓
1. 题目拆解
   - 关键词 / 中心词
   - 文体判断
  ↓
2. 结构模板
   - 按文体给 5 段式
  ↓
3. 段落支架
   - 每段给模板
   - 给填空提示
  ↓
4. 素材建议
   - 同主题素材库
  ↓
5. 词汇 / 句式升级
  ↓
6. 自问自答
  ↓
7. 自查清单
```

## 质量标准

- 模板可复用（同一文体不同题目能用）
- 不替学生写
- 不固化思维（提供多种开头）
- 自查清单可执行

## 护栏

1. **不替学生写**：只给支架
2. **不固化思维**：提供 2-3 种开头供选择
3. **不歧视**：素材避免涉及敏感话题
4. **不空泛**：每个建议具体可操作
5. **不超字数**：支架本身不超过 1500 字
6. **可降级**：基础薄弱学生可只用简化版

## 不要做的事

- 不要替学生写完整范文
- 不要给"万能模板"（误导学生）
- 不要在素材建议中包含"父母离婚"等敏感话题
- 不要在范文示例中"造假经历"
- 不要把"高级词汇"作为唯一标准
