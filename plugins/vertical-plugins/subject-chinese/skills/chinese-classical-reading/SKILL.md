# Chinese Classical Reading Skill

## 用途

把"古诗文"从"死记硬背"提升为"理解 + 鉴赏 + 应用"。

## 四层讲解

| 层级 | 名称 | 内容 | 面向 |
|---|---|---|---|
| L1 | 字词 | 通假字、词类活用、古今异义、一词多义 | 全部学生 |
| L2 | 句式 | 判断句、被动句、倒装、省略、虚词 | 中等以上 |
| L3 | 主题 | 作者情感、时代背景、主旨 | 中等以上 |
| L4 | 文化 | 典故、文化常识、文学史 | 拔高学生 |

## 触发场景

- 教师讲新文言文
- 学生古诗文失分
- 中高考古诗文复习
- 家长问"怎么帮孩子学古文"

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| text | ✅ | 古文原文 |
| author | ❌ | 作者 |
| era | ❌ | 朝代 |
| textbook_id | ✅ | 教材 ID |
| chapter_id | ✅ | 章节 |
| grade | ✅ | 年级 |
| focus | ❌ | 字词/句式/主题/文化 |

## 输出

### `classical_analysis.md`

```markdown
# 《爱莲说》讲解（教材 p.85）

> 作者：周敦颐 | 朝代：北宋 | 篇幅：119 字

## 一、字词过关（L1）

### 通假字
- "可爱者甚蕃" → 蕃 通 繁（多）

### 词类活用
- "香远益清" → 远（远播）形容词作动词
- "不蔓不枝" → 蔓（蔓延）、枝（生枝）名词作动词

### 古今异义
- "予独爱莲之出淤泥而不染"
  - 染：古义"污染"，今义"染色"
- "濯清涟而不妖"
  - 妖：古义"艳丽而不端庄"，今义"妖怪"

### 一词多义
- "之"
  - "水陆草木之花" → 助词，的
  - "莲之出淤泥而不染" → 助词，主谓之间，取独
  - "予独爱莲之" → 音节助词，无义

## 二、句式解析（L2）

### 判断句
- "予谓菊，花之隐逸者也" → ...者，...也
- "牡丹，花之富贵者也" → 同上

### 倒装句
- "何陋之有" → 宾语前置（教材未选但常考）

### 省略句
- "（予）独爱莲" → 省略主语

## 三、主题理解（L3）

### 作者情感
- 爱莲 → 追求高洁品格
- 叹菊 → 惋惜隐者稀少
- 鄙牡丹 → 讽刺追名逐利

### 时代背景
- 宋代士大夫精神：周敦颐借物抒怀
- 理学兴起：追求"格物致知"

### 主旨
- 通过对比，表达对高洁品格的追求
- 批判世俗追名逐利之风

## 四、文化常识（L4）

### 典故
- "陶渊明独爱菊" → 陶渊明《饮酒》"采菊东篱下"
- "世人盛爱牡丹" → 唐人爱牡丹，象征富贵

### 文化背景
- 莲花在佛教与儒家文化中的不同含义
- "君子"在儒家语境中的标准

## 五、考点预测

| 考点 | 出现频率 | 训练建议 |
|---|---|---|
| 词类活用 | ★★★ | 整理 10 个常见活用 |
| 倒装句识别 | ★★ | 标记教材中所有倒装 |
| 主题理解 | ★★★ | 背诵主旨句 |
| 虚词"之" | ★★★ | 整理 4 种用法 |
| 典故 | ★ | 关联文学史 |

## 六、配套练习

### 字词
1. 解释"蕃"在文中的意思
2. "蔓"在文中的词类活用
3. 翻译"濯清涟而不妖"

### 句式
1. 找出文中的判断句
2. "予独爱莲之出淤泥而不染" 是什么句式

### 主题
1. 文中"牡丹"象征什么？
2. 作者借"莲"表达什么志向？

### 综合
1. 比较周敦颐与陶渊明的品格追求异同
```

## 核心古文考点

### 字词类

| 类别 | 示例 |
|---|---|
| 通假字 | 距 → 拒 / 惠 → 慧 / 亡 → 无 |
| 词类活用 | 形容词作动词 / 名词作状语 / 使动 / 意动 |
| 古今异义 | "妻子"古义=妻子+儿女 / "中国"古义=中原 |
| 一词多义 | "之" "于" "而" "以" "焉" |

### 句式类

| 句式 | 标志 | 翻译 |
|---|---|---|
| 判断句 | ...者，...也 | 是... |
| 被动句 | 于 / 见 / 被 | 被... |
| 倒装句 | 之 / 是 | 调整语序 |
| 省略句 | ( ) 省略 | 补全 |

### 主题类

| 文体 | 主题方向 |
|---|---|
| 写景 | 借景抒情 / 寓情于景 |
| 抒情 | 志向 / 忧国 / 思乡 / 怀人 |
| 议论 | 治国 / 处世 / 学习 |
| 叙事 | 寓言 / 传记 / 故事 |

## 工作流

```
输入古文
  ↓
1. 教材定位
   - 原文 + 注释
   - page_ref
  ↓
2. L1 字词
   - 通假字 / 活用 / 古今 / 多义
  ↓
3. L2 句式
   - 判断 / 被动 / 倒装 / 省略
  ↓
4. L3 主题
   - 作者 + 背景 + 情感
  ↓
5. L4 文化
   - 典故 + 文化 + 文学史
  ↓
6. 考点预测
  ↓
7. 配套练习
```

## 质量标准

- 字词准确率 100%（基于权威工具书）
- 句式分类准确率 ≥ 95%
- 主题理解有依据（不空泛）
- 文化常识有出处
- 考点预测基于真题数据

## 护栏

1. **不曲解原文**：不强行赋予现代价值观
2. **不过度阐释**：避免"古文今译"式过度
3. **不脱离背景**：主题理解必须结合时代
4. **不堆典故**：关联的文化常识要服务于理解
5. **不歧视**：避免涉及对古人/朝代的主观评判

## 不要做的事

- 不要把古文讲成"封建糟粕"
- 不要把诗人讲成"完美人格"
- 不要用"现代白话文"思维解古文
- 不要给古文强行贴"政治"标签
- 不要把"之乎者也"当成"语法错误"
