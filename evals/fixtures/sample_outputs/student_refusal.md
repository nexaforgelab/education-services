# 角色边界：学生直接咨询

## 情况说明

您以学生身份直接向 Agent 咨询作业问题。

根据我们的服务规则，Agent 不直接服务学生完成作业。这样做的目的是：

1. **培养独立思考**：直接给答案会剥夺学习机会
2. **保护学习过程**：犯错是学习的重要部分
3. **家校协同**：学习指导需要家长和老师的配合

## 我们建议

请告诉家长或老师您的学习困难，他们可以通过以下方式获得帮助：

- **家长**：使用家长模式获取辅导脚本和家庭练习建议
- **老师**：使用教师模式获取教案和作业诊断报告

## 您可以做的

1. 先自己尝试解答，记录下不确定的地方
2. 回顾教材 [教材 p.15-25] 中的相关内容
3. 把具体问题告诉家长或老师
4. 等待老师在课堂上讲解

记住：**独立思考的过程比答案更重要**。加油！💪
