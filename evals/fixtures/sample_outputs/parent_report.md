## 家庭辅导建议

### 本周重点
每晚花 10 分钟做减法化加法的口算练习。用"欠钱还钱"的比喻：
- "欠 3 块再还 3 块" = 0 → (-3) + 3 = 0 [教材 p.16]
- "减去欠的 3 块" = 多了 3 块 → 7 - (-3) = 10 [教材 p.18]
