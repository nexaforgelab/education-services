# 教案：有理数加减法（45 分钟）

## 教学目标

- **知识与技能**：理解有理数加减法的符号法则，能正确进行有理数的加减运算 [教材 p.15]
- **过程与方法**：通过数轴演示探究规律，培养学生的归纳推理能力
- **情感态度**：体验数学与生活的联系，增强学习数学的信心

## 教学重难点

- **重点**：异号两数相加的符号判定 [教材 p.19]
- **难点**：减法统一为加法——"减去一个数等于加上它的相反数" [教材 p.18]

## 教学过程

### 导入（5 min）

教师提问："同学们，今天的天气预报说，气温从 -3°C 上升到 5°C，变化了多少？"

引导学生思考正负数在生活中的应用 [教材 p.2，第 1 章]

### 新授（25 min）

**1. 同号相加 [教材 p.16]**

数轴演示：
- (-3) + (-5) = -8（同负，绝对值相加，取负号）
- (+3) + (+5) = +8（同正，绝对值相加，取正号）

**2. 异号相加 [教材 p.19]**

数轴演示：
- (-3) + 5 = 2（异号，取大号，绝对值相减）
- 3 + (-5) = -2

归纳口诀：**同号相加取相同，异号相加取大号**

**3. 减法化加法 [教材 p.18]**

核心法则：减去一个数等于加上它的相反数

例题：7 - (-3) = 7 + 3 = 10 [教材 p.20]

### 巩固练习（10 min）

| 层级 | 题目 | 教材页码 |
|------|------|----------|
| 基础 | (-2) + (-3) = ? | p.16 |
| 基础 | 5 + (-3) = ? | p.17 |
| 中等 | (-7) + 4 = ? | p.19 |
| 综合 | 3 - (-5) + (-2) = ? | p.21 |

### 课堂小结（5 min）

1. 同号相加：符号不变，绝对值相加
2. 异号相加：取大号，绝对值相减
3. 减法化加法：减去一个数 = 加上它的相反数

## 板书设计

```
有理数加减法
┌─ 同号相加 → 取相同，绝对值相加 [p.16]
├─ 异号相加 → 取大号，绝对值相减 [p.19]  
└─ 减法化加法 → a-b = a+(-b) [p.18]
```
